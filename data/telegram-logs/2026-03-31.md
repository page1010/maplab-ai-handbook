## 根本原因

`handle_message`（第 528 行）收到你的訊息後，直接進 `_run_claude_guarded` → `claude_ask`，**等 Claude 跑完才回覆你**。

整個流程是**同步阻塞**：

```
你發訊息 → bot 收到 → 等 Claude（最多90秒）→ 才回你
```

中間你看不到任何反應，一旦 Claude 超過 90 秒就直接噴 timeout。

## 修法

在 `_run_claude_guarded` 裡，**進 semaphore 之前先送一個「收到，處理中」**：

```python
async def _run_claude_guarded(...) -> None:
    if _claude_semaphore.locked():
        await update.message.reply_text("⏳ Bot 正在處理上一則訊息，請稍候再試。")
        return
    await update.message.reply_text("⏳ 處理中…")   # ← 加這行
    async with _claude_semaphore:
        answer = await claude_ask(chat_id, user_message, system_extra)
        ...
```

這樣你發訊息後會立刻收到「處理中」，Claude 跑完再推結果，視覺上不會超時。
