# A6 訓練方法論 — 怎麼教 AI Agent 用系統

> **來源**：Owner 2026-04-09 用三個類比問題引導出的核心方法論。
> **結論**：不是寫死 if/else command parser，是給 AI「操作手冊 + QA 範例 + 安全框架」讓它自己判斷怎麼操作。

---

## Owner 的三個提問 + 答案

### Q1：假設要教會 AI agent 使用會計作帳系統，要怎麼教？

**答**：給完整的科目表 + 每種交易的分錄範例 + 系統操作 SOP（哪個畫面按哪個按鈕填哪個欄位）。AI 不需要懂會計原理，需要的是「看到發票 A → 對照範例 → 在系統裡重複同樣的操作步驟」。

**教的是**：pattern matching + 操作路徑，不是理論。

### Q2：假設要讓 AI agent 介入政府難用但無法大改的系統，要怎麼教？

**答**：不能改系統，所以教的是「繞路地圖」。把每一條常用流程錄成 step-by-step 截圖 + 每一步可能出現的錯誤訊息 + 對應的處理方式。AI 拿著這份地圖走，遇到岔路就查表。重點是把所有「人類踩過的坑」都寫進去。

**教的是**：操作路徑 + 錯誤處理表，系統不能改所以繞著走。

### Q3：假設這是醫療機械手臂的操作，沒有錯誤空間，要怎麼教會 AI agent？

**答**：不能讓 AI 自己判斷。每一個動作都要有 pre-check → execute → post-verify 三步。AI 做完一步，系統驗證結果正確才放行下一步。加上 hard limit（力道上限、角度範圍、速度限制），AI 在框框裡操作，框框外碰不到。

**教的是**：checklist + pre/post 驗證 + hard limit，不是「怎麼做手術」。

---

## 共同結論（三個都不是教「理解」）

| 場景 | 教什麼 | 不教什麼 |
|------|--------|---------|
| 會計系統 | 科目表 + 分錄範例 + 操作 SOP | 會計原理 |
| 政府系統 | 操作路徑 + 錯誤處理表 + 踩坑記錄 | 系統設計邏輯 |
| 機械手臂 | checklist + pre/post 驗證 + hard limit | 醫學知識 |
| **A6 報價系統** | **操作手冊 + QA 範例 + 安全框架** | **業務理論 / 寫死 if/else** |

## 錯誤的方法 vs 正確的方法

### ❌ 之前想的（寫死 command parser）

```
if (訊息開頭 == "報價") → parse 欄位 → call createQuote
if (訊息開頭 == "外帶") → parse → 外帶流程
if (訊息開頭 == "查") → SALES_INTAKE 搜尋
```

**問題**：
- 把 A6 當成 router 不是 agent
- 業務的指令不會按照固定格式
- 一旦遇到格式外的指令就壞掉
- 每個新情境都要加新的 if/else

### ✅ 正確的方法（給手冊讓 AI 自己判斷）

**給 A6 三樣東西**：

1. **操作手冊**（= 系統怎麼用）
   - 報價系統有哪些功能、每個功能的 input/output/觸發方式
   - createQuote + generateProposalV2 + Items 表 + SALES_INTAKE 的完整操作路徑
   - 包含 Slide proposal 產出邏輯

2. **QA 範例庫**（= 遇到這種情況怎麼做）
   - 每個活動類型 2-3 組指標性客人的完整對話 + 操作記錄
   - 「Mina 原話 → A6 判斷 → 系統操作 → 預期產出」
   - A6 讀完後「對號入座」— 新案件進來找最像的範例照做
   - **不是模擬寫死，是提供範例讓 AI 推理**

3. **安全框架**（= 什麼不能做 + 什麼要確認）
   - 硬限 / 確認點 / 錯誤處理

**A6 用的是 Claude，它讀完操作手冊 + QA 範例後，自然會知道「報價 李晴宜 週歲 20人」應該 call createQuote。不需要 regex，需要操作手冊。**

## 100 分目標（Owner 底線）

> 「不要定義 80 分報價單 能做到 100 分要 100 分那是我心中的底線」

100 分 = Mina 打開報價單直接能發，不用改。

A6 要做到：
- Mina 指定品名 → 填入 + 剩餘自動補齊
- 成本控制毛利率 ≥ 70%
- 每品足量 15-20（buffet 超量因子）
- 條款 + 車馬費 + 搬運費 + 訂金全自動
- 主動建議 upsell（pizza 等加購）
- **Slide proposal 也要能產**
