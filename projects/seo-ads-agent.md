## Canva 素材現況（2026-03-16）

Canva 設計連結：https://www.canva.com/design/DAHD4wpehE4/bRsNDBSCLqJz7bB9SGmNPw/edit

目前狀態：1 頁，多張 MAPLAB 活動照片拼貼模板（Birthday + Wedding Party 風格），有「BIRTHDAY」「WENDDING PARTY」字樣。
缺少：廣告文字層、CTA、品牌標語。

Meta 廣告需要幾張圖：
策略一冷受眾 C款需要 3 頁（3個廣告版本），各輸出 1080x1080 PNG，共 3 張：
- C-1：「質感不是偶然 / 是一桌一桌做出來的」
- C-2：「這樣的畫面，可以是你的婚禮」
- C-3：「派對美學，從餐桌開始」

目前這張是否堪用：
現有拼貼模板適合作為 IG 貼文或情緒板，但不適合直接用於 Meta 冷受眾廣告，原因：
1. 多圖拼貼在手機上視覺焦點不夠集中
2. WENDDING 拼寫錯誤
3. 沒有明確 CTA 和品牌標語
4. 冷受眾廣告需要單一視覺主題 + 核心文案

建議：保留拼貼設計給 IG 內容用，另外新增 3 頁做乾淨版廣告設計（單圖主視覺 + 文字層）。

## 策略建議紀錄

### v1.5 — 2026-03-16 | A3 Claude | Meta廣告代辦清單 + Google廣告診斷

#### Meta 廣告代辦（使用者執行）

立即處理（今日）：

1. 暫停「開發潛在客戶2026」
   每天白燒 NT$100，無廣告組合 → 暫停節省預算
   位置：廣告管理員 → 行銷活動 → 開發潛在客戶2026 → 關閉開關

2. 完成 Canva C款廣告素材並上傳（3張）
   Canva 新增 3 頁，完成 C-1/C-2/C-3 版本文字層
   輸出 1080x1080 PNG x 3 張
   上傳到廣告管理員：策略一-冷受眾-台南高雄25-40歲（adset 52608263444730）
   位置：廣告管理員 → 廣告組合 → 新增廣告 → 上傳圖片

3. 發佈策略一廣告組合
   廣告素材上傳後，確認廣告組合設定（預算/排程/受眾），點「發佈」

本週處理：

4. 建立 Meta Pixel 轉換事件
   - LINE 點擊追蹤（網站左下角 LINE 按鈕）
   - 表單送出追蹤
   - 電話點擊追蹤
   位置：Meta 事件管理工具 → 新增網頁事件

5. 建立自訂受眾（再行銷用）
   - 網站訪客（7/14/30天）
   - IG/FB 互動者（30/60天）
   - 點過 LINE 的人
   位置：廣告管理員 → 受眾 → 建立受眾 → 自訂受眾

6. 確認品牌知名度 A組「未發佈編輯」
   查看是否需要發佈或還原
   位置：廣告管理員 → 行銷活動 → 品牌知名度A組

下週以後：

7. 建立再行銷廣告活動（第二層暖受眾）
   對象：看過婚禮/週歲內容的人、點過 LINE 未成交者
   素材方向：FAQ（幾人起訂/提早多久/含不含佈置）

8. 評估 B組企業窗口 CPA NT$13 是否繼續

#### Google Ads 代辦

9. 確認轉換事件定義
   7次轉換是 LINE點擊 還是 表單/電話？
   位置：Google Ads → 工具 → 轉換

10. 提高關鍵字覆蓋或擴大受眾
    預算使用率僅 25%，可評估新增搜尋廣告活動或增加 PMax 資產群組

#### 下次 AI 接手時必問確認
- Meta：「開發潛在客戶2026」是否已暫停？
- Meta：策略一廣告素材（C-1/C-2/C-3）是否已上傳發佈？
- Meta：Pixel 轉換事件（LINE/表單/電話）是否已設定？
- Google：轉換事件定義為何？7次轉換是哪個事件？
- Google：預算使用率是否提升？（目標 >60%）
- 兩者：現在正在跑哪些廣告？有新增或停止的活動嗎？
