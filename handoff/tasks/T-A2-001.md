## 技術流程

1. Google Drive 找圖 → 驗證安全（無人臉/外部logo）
2. drive-usercontent thumbnail URL → fetch at w1600-h1200
3. Canvas → PNG → Clipboard API 跨分頁傳送
4. WordPress REST API /wp-json/wp/v2/media 上傳（含 SEO metadata）
5. /wp-json/wp/v2/posts/{id} 指派 featured_media
