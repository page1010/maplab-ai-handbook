# 頁面檢查器 — WP 頁面發布前必跑

版本：v1.0 | 建立：2026-03-29

---

## 原因
A2 修 WP 頁面時沒有固定檢查流程，導致 SEO meta 漏填、FAQ 缺失、素材與場景不一致。

## 規則段（Check）— 只判有沒有，不生成內容

| # | 檢查項 | 判定標準 | 通過 |
|---|--------|---------|------|
| 1 | title | ≤60 字、含主關鍵字 | ✅/❌ |
| 2 | meta description | ≤155 字、含 CTA | ✅/❌ |
| 3 | OG image + title | 有設定、尺寸 1200×630 | ✅/❌ |
| 4 | FAQ 區塊 | ≥3 題、有 schema markup | ✅/❌ |
| 5 | alt text | 所有圖片都有 alt | ✅/❌ |
| 6 | 首段摘要 | ≤150 字、含主關鍵字 | ✅/❌ |
| 7 | CTA | LINE/電話/表單至少一個 | ✅/❌ |
| 8 | 內連結 | ≥2 條指向其他場景頁 | ✅/❌ |
| 9 | 轉換事件 | GTM tag 存在（LINE click/form/phone）| ✅/❌ |
| 10 | 素材一致性 | 照片類別 = 頁面主題 | ✅/❌ |

## AI 段（Suggest）— 針對 ❌ 項目生成草稿

規則段跑完後，對每個 ❌ 項目：
- title：生成 3 個候選（含主關鍵字 + 地區 + 品牌名）
- meta description：生成 1 個（含 CTA + 數字 + 情感詞）
- FAQ：生成 3 題（從 A7 FAQ 庫 + 歷史詢問）
- alt text：根據圖片位置和頁面主題生成
- 內連結：建議連到哪些頁面

## 使用方式

A2 每次修 WP 頁面前：
1. 用 WP REST API 讀頁面 HTML
2. 跑規則段 10 項檢查
3. 輸出缺口清單
4. 跑 AI 段生成建議
5. 人工確認後才更新

禁止：跳過規則段直接生成內容。
