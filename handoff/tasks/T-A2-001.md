## 任務目標

為 MAPLAB Kitchen WordPress 網站全部 57 篇文章各配置一張**獨立唯一**的精選圖片（featured image），圖片來源為 Google Drive 公司相簿，並遵循 SEO 命名規範。

## 約束條件

- ✅ 食物特寫、場景佈置、無人場景 — 優先使用
- ❌ 人臉（含兒童）— 禁止
- ❌ 非 MAPLAB 品牌 logo — 禁止
- ❌ 酒類/飲料廣告圖 — 禁止
- ❌ 重複使用同一張圖片給多篇文章 — 禁止
- 圖片 SEO 命名格式：maplab-{場景關鍵字}-{內容描述}.png
- Alt text 格式：MAPLAB Kitchen {場景}｜{具體描述含長尾關鍵字}

## 技術流程

1. Google Drive 找圖 → 驗證安全（無人臉/外部logo）
2. drive-usercontent thumbnail URL + =w1600-h1200 → fetch blob
3. Canvas → PNG → Clipboard API 跨 Tab 傳輸
4. WordPress REST API /wp-json/wp/v2/media 上傳（含 SEO metadata）
5. REST API /wp-json/wp/v2/posts/{id} 設定 featured_media
6. 技能書參考：skills/gdrive-to-wordpress-upload-guide.md
