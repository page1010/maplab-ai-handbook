# MAPLAB IG 主題曲｜視覺與品牌 Brief

狀態：`VERIFIED_BRIEF / OWNER_LYRICS_GATE`

## 目的

寫一首能代表 MAPLAB、也能剪成 Reels 開場識別的主題曲。歌曲不是廣告口號集合，而是把帳號最有辨識度的「餐桌、相聚、暖光與節奏」變成可唱的記憶點。

## 已驗證的 IG 風格來源

- Owner 提供的 IG profile／Reels grid 截圖與 2026-06-17 Chrome 唯讀反讀。
- 帳號：`@maplabkitchen`。
- 公開定位：`外燴設計顧問`、`西式派對 / 品牌活動 / 婚禮茶會`、`美感 x 節奏`、`SINCE 2016`。
- 可見高表現樣本含約 13.6、16.7、28.5 秒 Reels；共同語言是暖柔低飽和、餐桌／食物近景、淺景深、少字、低壓銷售。
- 視覺模板：MAPLAB IG Soft v1；暖米／奶油白、細金線、柔和 crossfade、低調浮水印、無 debug counter。

## 創作取捨

- 選中：暖調 City-pop × 輕 Hip-hop，讓畫面有步伐但不吵，適合餐桌細節與慢速 zoom-out。
- 保留：女聲主唱＋短 spoken verse；副歌能被 15 秒 Reels 單獨使用。
- 不採：強烈 EDM drop、硬 trap、促銷口號、菜名或 SEO 關鍵字堆疊。它們會搶走 MAPLAB 原本的留白與質感。
- 核心記憶句：`把相聚端上桌`。

## 影片素材方向

1. 以 IG grid／既有貼文截圖做 1–2 秒品牌開場，只作版面記憶，不讓平台 UI 佔滿全片。
2. 主體改用 Owner 核准的真實活動影片：場景全景、食物近景、桌面佈置、花藝／手部細節。
3. 歌詞字幕每幕 6–12 字；食物與人物是主體，字幕不蓋畫面。
4. 完整版另做 16:9 歌詞影片；社群固定另做 exact 15.0 秒 9:16 Hook。
