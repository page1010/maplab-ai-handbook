WP 通道找到了,但找到的東西跟預期不一樣,先講這一句:站上根本沒有裝 WPCode。

實查:2026-09-18 win-01 自己盤點的外掛清單裡,WPCode、Code Snippets、HFCM 三個都沒有;管追蹤標籤的是 Site Kit 1.188.0,另外有 Header Footer Elementor 可以做 header 注入。所以「用 WPCode 佈碼」這條路現在不存在,不是沒去找。

已經給過的 WP 通道確實在,而且早就寫成程式了:REST 端點 www.maplabkitchen.com 的 wp-json/wp/v2,認證走 WP_USER 加 WP_APP_PASSWORD,或用 NOTION_TOKEN 去 Notion 保管室現拿;現成腳本有 scripts/wp_publish_draft.py、scripts/wp-audit.sh、automation/seo_factory、tools/wp_rankmath_recovery.py,規矩是只寫草稿不發布。缺的不是路,是這台 mac 的環境裡沒有設 NOTION_TOKEN 也沒有設 WP_APP_PASSWORD,所以現在跑會是 auth_missing。

更重要的一件事:Clarity 其實不必碰 WordPress。GTM 容器 GTM-T2Z52GP 已經活在站上,直接在容器裡開一個 Custom HTML tag 貼 Clarity 片段、觸發條件選 All Pages 就通了。不裝外掛、不改任何頁面、要停用隨時停。這是建議路線,Header Footer Elementor 當備案。

以下是 win-os 那台可以直接貼的 prompt,整段複製:

—— 從這裡開始 ——

角色:win-01(win-os 席位)的 bus 執行者。工作目錄 C:\agent-bus。本輪只做自檢與一張卡,不要擴張範圍。

第一步 自檢並回報,不可跳過:
1. 先確認登入是活的:執行 claude --version,再問一句最小提問看有沒有正常回答。前一次失敗原因是 OAuth session expired(2026-09-19 起),若這一步仍失敗就停在這裡,把錯誤訊息原文照抄回報,不要重試超過兩次、不要嘗試任何帳號輸入。
2. git pull,列出 inbox\win-01\ 底下所有 state 不是 done 的卡片檔名與 state。
3. 把第 1、2 項結果寫成回報,存到 C:\agent-bus\drafts\win-01\win01-selfcheck-20260923.md,然後 git add / commit / push,讓 mac 端看得到。

第二步 本輪指定卡:win01-ga4-clarity-install-20260918。這張卡已由 mac-a0 於 2026-09-23 20:05 從 pending 改成 blocked,解除條件是拿到 Clarity project id。在 project id 還沒給之前:不要嘗試登入任何帳號、不要猜密碼、不要重複重試觸發鎖定。

第三步 佈碼路線已經改了,不要再去找 WPCode:站上並沒有安裝 WPCode / Code Snippets / HFCM,管標籤的是 Site Kit 1.188.0。建議路線=在既有的 GTM 容器 GTM-T2Z52GP 新增一個 Custom HTML tag,貼 Clarity 片段,觸發條件選 All Pages,完全不動 WordPress。GTM 進不去時才退回第二方案:用站上已有的 Header Footer Elementor 做 header 注入。

第四步 回驗才算完成:佈完之後抓 www.maplabkitchen.com 的 HTML,以及 GTM 容器本體 googletagmanager.com/gtm.js?id=GTM-T2Z52GP,兩邊搜 clarity 字樣要從 0 變成有,把實際命中行貼進回執。沒有回驗數據不算 done。

紅線:不碰任何金融任務。帳密、授權碼、cookie 一律不輸入也不讀出、不寫進任何檔案。不刪頁、不改 WP 使用者權限、不動 Google Ads / Meta Ads / GTM 的付費與預算開關。不 publish,最多到草稿。產出一律寫 C:\agent-bus\drafts\win-01\,檔名含卡片 id 與日期。回執寫回 C:\agent-bus\outbox\win-01\,必含終態 done / partial / blocked;blocked 要寫卡在哪一步與錯誤訊息原文。

—— 到這裡結束 ——
