# R05 — 品牌語氣 vs 現有文章掃描

## 一、品牌語氣核心準則（5 條）

| # | 準則 | 說明 |
|---|------|------|
| 1 | **說場景，不硬講賣點** | 描寫空間、時刻、現場氛圍；賣點藏在敘事裡，不直接宣告「我最好」 |
| 2 | **具體名詞，禁用空泛形容** | 禁：精緻、超值、用心、最頂、CP值、保證滿意、佛心。改用：週歲派對餐桌、取餐節奏、桌面層次 |
| 3 | **保持開放感，不把話說死** | 避免「一定、保證、絕對、最好、唯一」；改用「也許、通常我們會這樣建議、會更適合」 |
| 4 | **不用說服式對比句型** | 禁：「不是...而是...」「不只...也...」「與其...不如...」 |
| 5 | **讓人被理解，不被推銷** | 語氣是「被穩穩接住」，不是被推進漏斗；不急著成交，先理解再引導 |

## 二、掃描結果 — 偏離準則的段落（最多 5 例）

### 案例 1 — 違規等級：中

**檔案**：`docs/a2a3/live-wp-rankmath-fact-check-2026-05-11.md`

**偏離段落**：
```
Title: 企業茶會點心外燴推薦：2026 精緻茶飲規劃｜MAPLAB Kitchen
H1: 企業茶會點心外燴推薦｜精緻甜點＋茶飲點心規劃｜MAPLAB Kitchen
```

**違反準則**：#2（「精緻」屬需少用字，出現兩次且在最顯眼位置）

**建議改法**：
```
Title: 企業茶會點心外燴推薦：台南商務活動茶飲配置指引｜MAPLAB Kitchen
H1: 企業茶會點心外燴推薦｜台南商務活動甜點＋茶飲配置｜MAPLAB Kitchen
```
移除「精緻」，改以「台南商務活動」為具體場景錨點，SEO 效果同等甚至更好。

---

### 案例 2 — 違規等級：輕

**檔案**：`docs/business-requirements/a6-usage-scenarios.md`

**偏離段落**：
```
大多以單份的精緻方式提供{B主食時加：，主食與肉類類型為盤裝分食享用}
```

**違反準則**：#2（「精緻方式」屬空泛形容，沒有具體描寫呈現形式）

**建議改法**：
```
大多以單份獨立盤裝提供，方便賓客取用且視覺整齊；主食與肉類類型為盤裝分食享用
```
改「精緻方式」為「單份獨立盤裝」，具體描寫服務形式，保留 C 級商務語氣。

---

### 案例 3 — 違規等級：中（潛在風險）

**檔案**：`skills/brand-voice-guide.md 第十一節（B2B 案例寫作）`  
（此文件本身是規範文件，不對外發布，但其中「各領域 TA 專屬寫作建議」的範例語句需確認不流入對外文案）

**偏離段落**（範例字詞）：
```
「恢弘大氣」、「出眾氣質」（企業廠辦寫法建議）
```

**潛在風險**：這兩個詞接近「過度讚美」語氣，若 agent 照搬至對外文案可能造成品牌語氣偏移。

**建議**：在技能書中加一行 Note：「以上為案例寫作參考用，對外發布文章仍應回到品牌語氣準則 §三核對」，避免混淆。

---

### 案例 4 — 違規等級：輕

**觸發類型**：Dispatch prompt 中對外廣告文案描述

**觀察**：在多份廣告 dispatch prompt（如 `TG-DISPATCH-20260714-091918-ads-performance-review`）中，受眾分析段落多次出現「精緻生活」作為受眾特徵描述（如：「注重精緻生活的媽媽」）。

**說明**：此為 TA 輪廓標籤，非對外文案，但若流入廣告文案複製即會觸發禁用詞。

**建議**：在 TA 輪廓文件加欄位說明：「此為分析標籤，對外廣告文案請依 brand-voice-guide §三替換」。

---

### 案例 5 — 整體性觀察

**發現**：docs/ 目錄內多份技術文件（如 `a6-training-methodology.md`, `user-manual-quote-assistant.md`）品牌語氣準則合規，無明顯違規。

**唯一持續風險**：SEO 文章 meta description 生成（由 A2 自動輸出）目前沒有系統性的品牌語氣過濾器，偶發「精緻」「用心」等語詞。

**建議**：在 `docs/seo-publish-checklist.md` E-1 條目現有 regex 掃描基礎上，加入「精緻 > 2次」警告，同時把替代說法直接列在 checklist 旁邊（目前只有指向 brand-voice-guide.md，沒有 inline 提示）。
