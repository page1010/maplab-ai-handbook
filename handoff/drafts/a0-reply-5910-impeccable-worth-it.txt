【Fable5 本人・同 session 續接】

結論先講:有參考價值,但不必裝,而且它補不到我們首頁真正的缺口。

它是什麼。Impeccable 是給 AI agent 用的設計規矩包,六十一條檢查,抓的是機器做介面時一直反射性用的那些預設值——漸層、置中、圓角、陰影那一類,一眼就知道是隨手生的。這種東西對「從零刻一個 React 介面」最有效,因為每一行樣式都在你手上。

我們的情況不一樣。首頁是 WordPress,版型吃主題跟區塊的限制,不是改 CSS 就能全改。所以真正搬得過來的是那份檢查清單的概念,不是那個工具本身。

質感的實話。外燴網站的質感九成在照片跟文案,不在按鈕圓角。我們首頁現在最像 AI 的地方是你自己抓出來的那幾處——動線好拿取那種句子、服務亮點自己講。那是文字問題,六十一條 CSS 檢查治不了。

還有一個時間點問題。九月十四號才做完 SEO 修復,十月十四號要拉數據覆盤成效。現在動視覺層,到時候數字變好變壞會分不清是內容還是改版造成的;而且動畫沒做好會拖載入速度,那是直接扣 SEO 分。要改,我建議排在覆盤之後。

裝的風險也講清楚。裝一個別人寫的 skill,等於把別人寫的指令灌進我們的 agent 照著跑。依我們自己定的注入政策,這種東西要先當資料讀過、鎖版本、不自動啟用——不是點一下 install 就好。

另外一件你可能不知道的:同類的設計指引我這邊本來就內建一份,沒花錢。要的是「有人盯設計細節」的話,我們手上已經有。

我沒有做的事我說清楚:我只看了你這張截圖,沒去讀那六十一條的實際內容,所以我不會說它會不會讓我們升級一級——我不知道。

建議一件不花錢也不裝東西的做法,等你一句再動:我拿設計自檢的概念對我們首頁跑一次,列出具體幾條——哪張圖該換、哪句話像 AI、哪裡間距不一致,你看了再決定要不要改。現在還沒做。
