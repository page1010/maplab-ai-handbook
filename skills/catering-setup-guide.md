# Catering Setup Guide — 外燴擺設指引技能書

版本：v0.1  
日期：2026-09-19  
用途：任何「外燴擺設、桌面配置、器皿安排、現場 setup、補餐動線、場地桌面視覺」任務

## 何時使用

看到以下需求就先讀本技能：
- 幫我排這場外燴怎麼擺
- 桌子這樣大小夠不夠
- 甜點 / 鹹點 / 飲料要怎麼分區
- 哪些餐點放高、哪些放低
- 花要擺哪裡
- 如何避免現場看起來太平
- 50 / 100 / 200 人怎麼改配置
- 室外 / 半戶外怎麼調整
- 幫我做擺設示意圖
- 活動照片看起來哪裡可以改

## 使用者最少要提供什麼

第一輪最好拿到：
- 活動類型
- 人數
- 室內 / 半戶外 / 戶外
- 桌子數量
- 每張桌大約長寬
- 菜單 / 品項數量
- 可用器皿 / 高架 / 托盤
- 是否有飲料區
- 是否需要花材
- 1–3 張場地或過往 reference 照（有就用，沒有不強迫）

缺硬資料就明確列出，不自行補值。

## 標準輸出順序

### 1. 先做硬限制
先確認：
- 桌面是否容得下
- 客人從哪邊拿
- 補餐從哪邊進
- 是否會堵住
- 哪些餐點有溫控 / 融化 / 風吹風險
- 高架是否安全
- 花材是否擋視線或取餐

### 2. 再做視覺層次
原則：
- 至少 2 層，通常 3 層即可
- 不為了高度而堆高
- 主視覺不一定在正中央
- 避免整桌平均散開，應形成 1–2 個視覺群
- 飲料與主取餐區通常不要共用同一個瓶頸
- 裝飾是配角，食物與使用動線是主角

### 3. 再給方案
最多 2–3 個方案，說明：
- 適合原因
- 優點
- 風險
- 哪些條件變動時要換方案

不要做「最好 / 最美」排名。

### 4. 產生一頁式現場指引
格式：
- Step 1：桌布 / 大器皿
- Step 2：高架
- Step 3：主鹹點
- Step 4：甜點
- Step 5：飲品
- Step 6：花材 / 小裝飾
- Step 7：動線 QA
- Step 8：拍照角度 QA

### 5. 活動後回收
活動結束至少記：
- 哪裡塞車
- 哪裡拿取不順
- 哪個盤太小 / 太大
- 哪些品項補太頻繁
- 花材是否干擾
- 哪個角度拍起來最好
- 下次應改的 1–3 條規則

## 圖像使用規則

### 可以生成
- 俯視配置圖
- 正視高度圖
- 線框 schematic
- 器皿 / 區域標註
- 動線箭頭
- 概念式 mockup

### 不可以混淆
- AI 圖必須標 `CONCEPT_PREVIEW`
- 真實案例一定由 A4 素材庫取
- 不產生可冒充 MAPLAB 真實出餐的假食物案例

## 快速 Prompt：一般場次

```text
你是 MAPLAB Catering Setup Advisor。

請根據以下資料，先做硬限制檢查，再做擺設建議：
- 活動類型：
- 人數：
- 場地：室內 / 半戶外 / 戶外
- 桌子：
- 菜單：
- 可用器皿：
- 飲品：
- 花材：
- 其他限制：

輸出順序：
1. MISSING_INPUT
2. hard constraints / risks
3. 2–3 個可執行方案
4. 每區餐點、器皿、高度、間距
5. guest flow / refill flow
6. 一頁式 setup checklist
7. 若能做圖，提供 top-down schematic + front-elevation schematic

規則：
- 不猜器皿庫存或尺寸。
- 不把 AI 圖當成真實案例。
- 優先使用真實 MAPLAB reference。
- 安全、取餐與補餐動線優先於裝飾。
```

## 快速 Prompt：活動後檢討

```text
請把這場外燴做 post-event setup review。

輸入：
- 原 setup plan
- 最終人工調整
- 1–3 張真實現場照片
- 現場回饋

請輸出：
1. plan vs actual 差異
2. 哪些規則有效
3. 哪些位置造成壅塞 / 補餐問題
4. 器皿 / 高度 / 花材問題
5. 新 rule candidates
6. 每條候選規則的 evidence 與 confidence
7. 不准自動把候選規則升級成正式規則
```
