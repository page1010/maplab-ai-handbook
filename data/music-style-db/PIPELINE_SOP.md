## 🎬 2. 視覺與 5 層微動態物理引擎標準

每個場景需具備真正「活起來」的氛圍動態，避免單純畫面縮放（Zoompan），標準包含 5 大動態層：

| 動態層 | 物理機制 | 渲染技術 |
| :--- | :--- | :--- |
| 1. **水面波紋與霓虹倒影** | 水面隨正弦諧波產生橫向置換，倒影產生光暈閃爍 | Scipy `map_coordinates` 雙線性置換 + 水面羽化遮罩 |
| 2. **水面落雨漣漪** | 雨滴隨機落於水面，產生透視扁平橢圓同心圓擴散並淡出 | 週期相位 `(t - t_0) % T` 嚴格保證首尾完全無縫 |
| 3. **熱氣與蒸氣** | 咖啡杯 / 壺口溫潤白煙隨風飄散、波浪起伏、向上膨脹消散 | 縱向速度與正弦擺幅合成高斯羽化粒子流 |
| 4. **斜細雨絲** | 窗外/街景下落細雨絲，帶動態模糊與半透明質感 | 垂直位移取模 `(y_0 + v_y * t) % H` 整數倍循環 |
| 5. **火光與霓虹呼吸** | 煤油燈/防風油燈燭火微弱閃動，霓虹招牌微幅電壓呼吸 | 徑向衰減光暈疊加多頻率正弦微幅光變 |

* **循環週期**：標準為 **8.0 秒 / 25 fps（200 幀）**，首尾幀完全相同，保證 100% 無縫。
* **標準渲染腳本**：`/Users/pagemacmini/maplab-ai-handbook/scripts/render_lofi_rain_loop.py`

## 🎵 4. Suno 音樂產出標準

1. **風格紅線**：
   - 必含 `instrumental`, `no vocals`。
   - 嚴禁人聲口白或外燴引流文字干擾音樂純粹度。
   - BPM 落在 75 ~ 95（Chillhop / Lofi）或 110 ~ 125（City Pop / Synthwave）。
2. **世界觀融合**：
   - 保留東方老台南氛圍（如：遠處短波電台、黑膠底噪、老鋼琴、偶爾點綴的五聲音階）。
3. **母帶合成**：
   - 使用 `/Users/pagemacmini/maplab-ai-handbook/scripts/mtr_pipeline.py` 將 Suno 音軌與 8 秒微動畫自動平鋪無縫合成為 YouTube 最終版本。
