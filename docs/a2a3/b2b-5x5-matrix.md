# MAPLAB B2B 5x5 Source Matrix

版本：v1.0
日期：2026-05-11
用途：把相片日期、Google 報價單、IG 發文、既有文章與頁面對齊，先把素材整理成可用的 5x5 矩陣。

> 這份矩陣不是要再生頁面，而是先把「哪些照片 / 哪些日期 / 哪些報價單 / 哪些 IG 發文」能互相對上的素材釘住。
> 後續頁面、廣告、素材庫都以這份矩陣為準。

## 使用方式

1. 先從相片日期找 Google 報價單名稱。
2. 再用同日期 / 同活動名稱去對 IG 是否有發文。
3. 有 IG 發文就把 caption / 圖片截圖 / 翻拍素材補進同一包。
4. 最後再回到對應的 WordPress 頁面補案例與 SEO。

## 這份矩陣先做什麼

- 先補 IG 圖片與 caption 對應
- 再把同日期的 Google 報價單名稱對上
- 再檢查 IG 是否有發文資料
- 最後才進 WordPress 頁面與 Rank Math

## 完成標準

每個 category 至少要有 5 個可確認素材，而且每筆最好能同時對上：

1. 照片日期
2. Google 報價單名稱
3. IG 發文或 caption
4. WordPress 對應頁面

只要四者對上三個以上，就可以進素材庫；如果只對到一個，先放候選，不急著發文。
