## 5. 本批執行順序

1. 先跑 `企業會議 / 茶點 / 辦公室`
2. 再跑 `開幕 / 品牌活動 / VIP 接待`
3. 接著跑 `學校 / 研討會 / 畢典`
4. 文化場館先做支援案例，不新開主頁
5. 完成後再用 Browser / Computer Use 逐頁看 preview.html 與 Rank Math 設定

## 6. 寫作與 SEO 規則

- 不寫價格
- 不寫空泛稱讚
- 句子以場景為主，不以銷售為主
- 先寫真案例，再寫 FAQ
- 內連只導向對應 cluster，不要全部回首頁
