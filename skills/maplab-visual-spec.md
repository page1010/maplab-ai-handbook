### 使用規則

**主視覺組合**（推薦）：
- 背景：奶油白 + 暖米
- 文字：深橄欖（主）+ 棕褐（重點）
- 輔助：鼠尾草

**場景專屬色**：
- 週歲派對：裸粉 + 奶油白
- 婚禮外燴：裸粉 + 暖米
- 企業活動：深橄欖 + 暖米

**禁止使用**：
- ❌ 高飽和度螢光色（螢光黃、螢光橙）
- ❌ 純黑 `#000000` 作為大面積背景
- ❌ 超過 3 個主色同時出現在單一畫面

## 二、字體與排版規範

### 字體建議

| 層級 | 繁體中文 | 英文/數字 | 場景 |
|------|---------|---------|------|
| 主標題 H1 | 思源宋體 / Noto Serif TC | Playfair Display | 品牌大標、形象頁 |
| 次標題 H2/H3 | 思源黑體 / Noto Sans TC | Lato / Inter | 服務介紹、區塊標題 |
| 內文 Body | 思源黑體 Regular | Inter Regular | 文章、說明文字 |
| 標籤/說明 Caption | 思源黑體 Light | Inter Light | 圖片說明、日期 |
| IG 貼文覆蓋字 | 黑體加粗 或 宋體 | Playfair Display | 貼文視覺字體 |

### 尺寸規範（px 基準）

| 元素 | 尺寸 | 行高 | 字距 |
|------|------|------|------|
| H1 主標題 | 36-48px | 1.3 | -0.02em |
| H2 次標題 | 24-30px | 1.4 | -0.01em |
| H3 小標題 | 18-22px | 1.5 | 0 |
| 內文 | 15-16px | 1.8 | 0.01em |
| Caption | 12-13px | 1.6 | 0.02em |
| IG 覆蓋字 | 32-56px（依畫面比例調整） | 1.2 | -0.02em |

### 排版原則

1. **留白優先**：元素間距寬鬆，不塞滿版面
2. **文字不超過 3 層**：同一區塊最多主標題 + 副標題 + 說明
3. **禁止過多字體混用**：同一畫面最多 2 種字體
4. **中英文混排**：中文宋體 + 英文 Playfair Display（品牌感組合）

## 三、影像處理規範

### 白平衡 / 曝光設定

| 設定項目 | 目標值 | 說明 |
|---------|--------|------|
| 白平衡 | 暖調（5500-6500K） | 避免冷藍色調，保持食物暖感 |
| 曝光補償 | +0.3 ~ +0.7 EV | 略過曝讓畫面通透，食物色澤更鮮豔 |
| 對比度 | 降低 -10 ~ -15 | 柔化陰影，保留細節 |
| 高光 | 降低 -20 ~ -30 | 防止白色餐具/食物過曝 |
| 陰影 | 提亮 +10 ~ +20 | 暗部細節保留 |

### HSL 調整方向

| 色相 | 飽和度 | 明度 | 目的 |
|------|--------|------|------|
| 橙/黃（食物色） | +10 ~ +15 | +5 | 食物更誘人 |
| 綠（蔬菜/植物） | +5 ~ +10 | 0 | 自然感 |
| 紅/粉（花朵/裝飾） | +5 | 0 | 保持自然 |
| 藍（背景/空間） | -10 | 0 | 避免冷調干擾 |

### 裁切規範

| 用途 | 比例 | 解析度 | 說明 |
|------|------|--------|------|
| IG 方形貼文 | 1:1 (1080×1080px) | 72dpi | 主力貼文格式 |
| IG 直式貼文 | 4:5 (1080×1350px) | 72dpi | 佔版面比例高 |
| IG Stories / Reels | 9:16 (1080×1920px) | 72dpi | 全螢幕格式 |
| FB 橫式貼文 | 16:9 (1200×675px) | 72dpi | FB 主力 |
| 官網橫幅 | 16:9 或 2:1 | 150dpi | Banner 用 |
| WordPress 精選圖片 | 16:9 (1200×675px) | 72dpi | SEO 文章 |

### 文字覆蓋規則

**可覆蓋情況**：
- 畫面有足夠留白區域（≥30% 空白面積）
- 文字顏色與背景對比度 ≥ 4.5:1

**覆蓋位置優先順序**：
1. 左下角（自然視覺落點）
2. 上方1/3（配合標題）
3. 下方1/3（配合說明文字）

**禁止覆蓋**：
- ❌ 直接蓋在食物主體上
- ❌ 小字蓋在複雜背景上
- ❌ 與食物色相近的文字顏色

## 四、IG 版面系統

### 內容桶比例（Content Bucket）

| 內容桶 | 比例 | 說明 |
|--------|------|------|
| 場景紀錄（外燴現場） | 40% | 真實活動照，建立信任感 |
| 食物特寫 | 25% | 誘人食物細節，增加渴望感 |
| 桌面佈置 | 20% | 美感呈現，強化品牌質感 |
| 品牌/文字卡 | 10% | 節氣、報價說明、小知識 |
| 幕後花絮 | 5% | 主理人視角，增加親近感 |

### 九宮格視覺模板

```
┌─────────┬─────────┬─────────┐
│ 場景1   │ 食物特寫│ 桌面佈置│
│ (暖棕調)│ (特寫)  │ (俯視)  │
├─────────┼─────────┼─────────┤
│ 文字卡  │ 場景2   │ 食物特寫│
│ (奶油白)│ (側景)  │ (橫式)  │
├─────────┼─────────┼─────────┤
│ 桌面佈置│ 幕後花絮│ 場景3   │
│ (細節)  │ (主理人)│ (全景)  │
└─────────┴─────────┴─────────┘
```

**九宮格原則**：
- 同一行不放 2 張顏色相近的照片
- 文字卡不連續出現超過 2 格
- 整體色調維持暖調統一感

### 發文節奏

| 平台 | 頻率 | 最佳時間 | 說明 |
|------|------|---------|------|
| IG 貼文 | 3-4 次/週 | 週一/三/五 20:00-21:00 | 穩定頻率比量重要 |
| IG Stories | 每日 1-3 則 | 任意時間 | 保持帳號活躍度 |
| IG Reels | 1-2 次/週 | 週二/四 19:00-20:00 | 演算法加權 |
| FB 貼文 | 2-3 次/週 | 週一/三/五 12:00 或 19:00 | FB 午休/下班族群 |
| Threads | 3-5 次/週 | 不限 | 較輕量，觀察/感想為主 |

## 五、設計元素與輸出規範

### Logo 使用規則

| 版本 | 用途 | 最小尺寸 | 背景限制 |
|------|------|---------|---------|
| 深色版（深橄欖色） | 淺色背景使用 | 80px 寬 | 奶油白/暖米背景 |
| 淺色版（奶油白） | 深色背景使用 | 80px 寬 | 深橄欖/棕褐背景 |
| 單色版（黑/白） | 印刷/壓紋用 | 60px 寬 | 任意對比背景 |

**Logo 禁止使用**：
- ❌ 拉伸或壓扁比例
- ❌ 置於複雜背景上且沒有淨空區
- ❌ 加陰影效果
- ❌ 旋轉使用

**Logo 淨空區**：Logo 周邊保留至少等同 Logo 高度 1/4 的空白

### Icon 系統

| 風格 | 線條粗細 | 圓角 | 說明 |
|------|---------|------|------|
| Line icon（輪廓） | 1.5-2px | 圓角 4px | 主要 UI icon |
| Filled icon（實心） | — | 圓角 4px | 強調/選中狀態 |

**Icon 色彩**：搭配文字同色（深橄欖或棕褐），不單獨使用鮮豔色

### 裝飾元素

| 元素 | 使用場景 | 規則 |
|------|---------|------|
| 細線分隔 | 區塊分隔 | 炭黑 0.5-1px，長度不滿版 |
| 點狀排列 | 背景裝飾 | 低透明度（15-25%），不搶主視覺 |
| 有機形狀 | 色塊背景 | 不規則圓角，配合暖米/裸粉色 |
| 手寫風筆觸 | 特殊活動貼文 | 非常規，慎用，保持乾淨感 |

### 黃花（乾燥花）使用規則

黃花（芒草、乾燥菊、帝王花）是 MAPLAB 視覺的標誌性裝飾元素。

**使用規則**：
1. **位置**：畫面角落或邊緣，作為自然框架，不蓋過主體
2. **比例**：佔畫面面積不超過 15%
3. **色調**：保持自然乾燥色（棕黃/米白），不做人工染色
4. **數量**：1-3 枝為佳，過多顯得雜亂
5. **配搭**：最適配合奶油白/暖米背景，避免配深色背景

**黃花禁用情境**：
- ❌ 企業/商務場景（過於柔美）
- ❌ 非食物類型貼文的主角（它是配角）
- ❌ 與其他強烈裝飾元素（鮮花、植物）同時大量出現

### 命名規則（檔案輸出）

```
格式：maplab-{場景}-{內容描述}-{版本/日期}.{副檔名}

範例：
maplab-birthday-table-setup-v1.jpg      → 週歲餐桌佈置 v1
maplab-corporate-catering-closeup.jpg   → 企業外燴特寫
maplab-ig-post-20260329.png             → IG 貼文視覺（含日期）
maplab-logo-dark-v2.svg                 → Logo 深色版 v2
maplab-banner-wedding-2026.jpg          → 婚禮橫幅 2026
```

**命名禁止**：
- ❌ 空格（用 `-` 取代）
- ❌ 中文字符
- ❌ 特殊符號（括號、驚嘆號等）
- ❌ 無意義流水號（img001.jpg）

## 八、QA 視覺檢查清單

每次輸出視覺素材前確認：

### 色彩
- [ ] 使用色彩限於 7 色票範圍內？
- [ ] 同一畫面主色不超過 3 個？
- [ ] 有場景色（週歲/婚禮用裸粉、企業用深橄欖）正確對應？
- [ ] 無高飽和螢光色？

### 字體排版
- [ ] 字體選用符合規範（宋體/黑體 + 英文配對）？
- [ ] 同一畫面字體不超過 2 種？
- [ ] 文字大小層次清楚（主標題 > 副標題 > 說明）？
- [ ] 留白充足？

### 影像
- [ ] 色調偏暖（避免冷藍）？
- [ ] 白色餐具/食物無過曝？
- [ ] 圖片比例符合輸出平台規格？
- [ ] 食物特寫清晰，有食慾感？

### Logo / 品牌元素
- [ ] Logo 沒有拉伸變形？
- [ ] Logo 淨空區保留？
- [ ] 黃花使用不超過 15% 版面且非主角？
- [ ] 裝飾元素不搶主視覺？

### 文字覆蓋（如有）
- [ ] 文字區域有足夠留白（≥30%）？
- [ ] 文字與背景對比度 ≥ 4.5:1？
- [ ] 沒有蓋在食物主體上？
- [ ] 沒有禁用字詞？（對照 brand-voice-guide.md）

### 命名 / 輸出
- [ ] 檔名符合 `maplab-{場景}-{描述}` 格式？
- [ ] 無中文/空格/特殊符號？
- [ ] 解析度符合平台需求？
