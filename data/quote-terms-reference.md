# 報價單合約條款參考手冊

> 來源：932 份報價單原始資料
> 整理日：2026-03-29
> 用途：業務參考用，記錄現行實際使用中的條文原文

---

## 一、個人版條款

> 適用對象：個人客戶（非公司行號）
> 格式特性：較口語化，以 LINE 訊息或文字報價呈現

### 標準版（最常見）

```
匯款資訊如下：
中國信託822 / 西台南分行
帳號：222510859464
戶名：莊貴棻
匯款後，再麻煩提供後五碼對帳。
如需收據請提前告知，當日會附上。

（1）已保留檔期，預約付訂後取消，欲收取訂金50%作為成本取消費
（2）用餐日期14天內取消（或變更），收取訂金80%作為食材成本取消費
（3）用餐當日取消（或變更），收取訂金100%作為取消與變更費
```

### 簡化版（部分報價使用）

```
訂金$[金額]，尾款$[金額]於活動日前匯款完成。
```

```
尾款活動「三日前」匯款完成
```

### 付款說明標準套語（高頻出現）

```
匯款後，再麻煩提供後五碼對帳。如需收據請提前告知，當日會附上。
```

## 二、企業版條款

> 適用對象：公司行號（需統編、核銷用）
> 格式特性：正式合約格式，含條款編號

### 標準版（最常見）

```
▶簽約使用條款及細則：
（1）鑒於部分企業用戶之會計核銷，此合約僅供公司行號使用。
（2）本合約代表雙方對於___年___月___日之活動做出預約，並確認保留檔期。
（3）已保留之檔期，如有於十日內取消服務之情事，須支付活動合約總金額之20%材料損失費。
（4）活動當日取消（或臨時有地點、菜色、時間之變更），將酌情形額外收取費用。

‣活動指定地點如超過30分鐘距離須收取車馬費，諮詢依地區實際公里數各別報價。
‣擺設場地有樓層必須預先告知，2F以上無電梯須收取$1,000搬運費，有人協助收取$500元搬運費。
 若當日電梯因故無法使用，則現場以現金加收$1,000樓層搬運費。
```

### 嚴格版（部分企業訂單使用）

```
（4）活動當日取消或更動者，須支付總金額80%作為食材與人力成本賠償，恕不退還任何已付金額。
```

## 三、特殊條款參考區

> 以下條文為 932 份報價中曾出現過的特別條文，不在標準版本內，供業務參考。

### 3-1 搬運費細則

```
擺設場地有樓層必須預先告知，2F 以上無電梯須加收搬運費。
若當日電梯因故無法使用，則現場以現金加收$1,000樓層搬運費。
有人協助搬運：$500。無人協助：$1,000。
```

出現頻率：196 次（其中 2F搬運費 $800 最常見：38 次）

> 備註：歷史報價中 $800 / $1,000 兩種金額均有出現，企業版條文明文 $1,000 / $500。

---

### 3-2 車馬費說明

```
‣活動指定地點如超過30分鐘距離須收取車馬費，諮詢依地區實際公里數各別報價。
```

歷史金額區間：

| 地區 | 常見金額 | 出現次數 |
|------|---------|---------|
| 近郊（高雄岡山/橋頭） | $400–$500 | 15 |
| 高雄市區 | $600–$800 | 19 |
| 嘉義 / 高雄遠區 | $1,000–$1,200 | 9 |
| 台中以南跨縣市 | $1,800–$2,000 | 10 |
| 台北 / 北部 | $3,000 | 3 |

---

### 3-3 長桌租借

```
租借長桌一張 $400（依場地需求評估數量）
```

出現頻率：585 次。部分早期報價為 $350/張。

---

### 3-4 加購一次性餐具

```
加購一次性餐具 $10/組（含餐盤、叉子、飲料杯）
基本贈品：15 組（含在套餐內）
```

出現頻率：474 次。

---

### 3-5 加購花藝裝飾

```
加購餐檯鮮花裝飾（金額依季節另報）
加購鮮花小瓶（金額依季節另報）
```

出現頻率：餐檯鮮花 148 次、小瓶花藝 144 次。

---

### 3-6 打包盒

```
外帶打包盒 $8/個
```

出現頻率：177 次。

---

### 3-7 招待人數加份

部分報價有備註「含主辦方招待份數」或「加購額外招待份」，出現 36 次，無固定金額格式，通常另行備註。

---

### 3-8 統編 / 發票

出現頻率：12 次。目前無標準格式，以手動備註為主（「統編：XXXXXXXX」）。

---

### 3-9 服務含項標準套語

以下文字在 579 份報價中出現，為高頻固定說明：

```
【以上含專人到場餐檯氛圍陳列、乾燥花藝基本裝飾、撤場服務、桌巾、一次性免洗餐具。】
```
