# 下三個任務回報模組 — 每個斷點必用

版本：v1.0 | 建立：2026-03-28

---

## 規則

每次完成一個任務或遇到斷點時，必須回報接下來三個待做任務的：
1. 編號和名稱
2. 做什麼（目標）
3. 用什麼方法（工具/API/平台）
4. 具體步驟（3-5 步）

## 格式

```
📋 下三個任務預覽：

#[N] [任務名稱]
目標：[一句話]
方法：[工具/平台]
步驟：1. ... 2. ... 3. ...

#[N+1] [任務名稱]
目標：[一句話]
方法：[工具/平台]
步驟：1. ... 2. ... 3. ...

#[N+2] [任務名稱]
目標：[一句話]
方法：[工具/平台]
步驟：1. ... 2. ... 3. ...
```

## 觸發條件
- 任務完成後
- 遇到斷點無法繼續時
- Owner 問「接下來做什麼」時
- 每次 session 結束前
