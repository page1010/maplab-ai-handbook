## 長版

- 16:9、75–90 秒歌詞影片；每個段落用不同案例畫面，但維持暖柔低飽和。
- Intro 可用帳號版面截圖建立品牌記憶，主歌後改用真實活動影片，不把 IG UI 當主體。
- Verse 依序：場地準備 → 花與餐盤 → 食物近景 → 賓客相聚的非具名遠景。
- Chorus 回到完整餐桌與品牌署名；字幕採逐句進場，不做卡拉 OK 式滿版字。
- 素材不足時只用核准靜幀＋慢速 zoom-out，不補造不存在的活動畫面。
