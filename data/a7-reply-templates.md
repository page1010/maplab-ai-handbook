## 使用說明（1 分鐘讀完）

1. 客戶訊息進來 → 看「模板速查表」找對應情境
2. 複製對應模板 → 替換 [名] / [日期] 等變數
3. 確認語氣符合品牌（溫暖、具體、不過度承諾）→ 發送
4. 標記客戶標籤（🔴🟠🟡等）→ 決定下一步

**不確定用哪個模板？** 先問自己：客戶是要報價、還是純問問題？
- 要報價 → Q1 或 Q2
- 純問問 → Q3–Q7
- 報價後追問 → Q8
- 人數/地區不符 → Q9
- 曾合作/長期配合 → Q10

## Q1 — 補問模板（表單空白或資訊不完整）

**用時機：** 客戶填了表單但關鍵欄位空白/模糊，或自由文字詢問但細節不夠

```
[名]您好，感謝您的訊息！

為了幫您準備最適合的方案，想跟您確認幾個細節：

① [缺的欄位A，例如：活動預計哪一天？]
② [缺的欄位B，例如：大約幾位朋友一起？]
③ [缺的欄位C，例如：活動在室內還是戶外？]

確認後我們會在 1–2 個工作天提供菜單方案給您參考。
```

**補問優先順序：** 日期 → 人數 → 活動類型 → 場地 → 預算
**規則：** 一次最多問 3 題；已知的跳過；收齊日期+人數+類型+場地+聯絡方式 → 送報價

## Q2 — 報價引導模板（直接問價格）

**用時機：** 客戶跳過選單直接問「多少錢」「費用怎麼算」

```
感謝您的詢問！我們的報價依人數、活動類型和場地而定，想先確認幾項再為您估算：

① 活動預計哪一天？
② 大約幾位朋友/同事？
③ 在哪裡舉辦？室內或戶外？

確認後會提供完整菜單方案與報價給您參考。
```

**門檻資訊（必要時補充）：**
- 外燴正餐：最低 20 人起
- 外帶：低消 NT$3,000
- 高雄地區外燴：低消 NT$25,000（含外送）
- 出車費：NT$10,000 起

## Q3 — 外帶模板

**用時機：** 客戶選 #5 或直接問外帶/禮盒

```
外帶低消 NT$3,000 起，品項以手工甜點和輕食為主，建議提前兩週預訂。

方便告訴我：
① 大約幾份？
② 希望哪天取餐？
③ 自取，還是需要外送？（市區外可搭配 Lalamove）

確認後我傳品項和報價給您。
```

## Q4 — 場佈/加購模板

**用時機：** 客戶問甜品桌、Candy Bar、花藝、酒水等加購項目

```
基本餐檯佈置已包含在外燴服務裡。

[Candy Bar / 甜品桌 / 酒水吧 / 花藝] 可以加購，費用會在報價中分列說明。

請問有特定的風格或主題嗎？方便的話也告訴我活動日期和人數，我一起幫您規劃。
```

## Q5 — 地區回覆模板

**用時機：** 客戶詢問能否到某地點服務

**台南市區（免費）：**
```
台南市區是我們的主要服務範圍，市區內無額外外送費用。請問活動場地的地址方便提供嗎？
```

**高雄（加價）：**
```
高雄地區有提供服務，外燴低消 NT$25,000 起（含外送費）。請問活動日期和人數大概是？
```

**嘉義/屏東（另計）：**
```
嘉義/屏東地區可以服務，外送費依距離另計，確認地址後我幫您估算。請問活動地址方便告訴我嗎？
```

**彰化以北（婉拒）：**
```
感謝您的詢問。目前服務範圍以台南為主，[地點] 暫時沒有提供服務。如果未來有台南場次，歡迎再聯繫我們。
```

## Q6 — 檔期確認模板

**用時機：** 客戶確認日期可行性

```
我先確認 [日期] 的檔期。

[✅ 可以] 這天目前可以，建議盡早確認以保留檔期。
[❌ 已滿] 這天已被預訂，最近可安排的是 [替代日期]，或其他日期也歡迎提出。
```

**注意：** 旺季（10–12 月、3–5 月）建議提前 4 週預訂；多場次需一次排定。

## Q8 — 報價後跟進模板

**用時機 A — 報價後 7 天未回覆：**
```
[名]您好，之前傳給您的報價不知道看過了嗎？
菜色或預算有任何想調整的都可以討論，檔期有限，建議盡早確認。
```

**用時機 B — 客戶覺得貴，要調整預算：**
```
了解您的預算方向，可以在菜色組合上做調整：

例如減少 [品項A] 或改搭 [替代品項]，整體可降到 [價格區間]。

我重新搭一版方案給您參考？
```

**規則：** 不直接降價，改用菜色調整。請 A5 重組 2–3 套方案再回覆客戶。

## Q9 — 婉拒模板

**人數不足（< 20 人）：**
```
感謝您的詢問。外燴正餐目前最低接 20 位，您這次 [X] 位的話，可以參考我們的外帶方案（低消 NT$3,000 起），品項也蠻豐富的。

需要的話我傳外帶品項給您參考？
```

**地區不服務：**
```
感謝您的詢問。目前服務範圍以台南為主，[地點] 暫時沒有提供外燴服務。如果未來有台南場次，歡迎再聯繫我們。
```

**規則：** 語氣溫暖但明確，不說「可能可以」。人數不足可導向外帶。

## Q10 — 回頭客 / B2B 模板

**回頭客：**
```
[名]您好，很高興再收到您的訊息！

上次 [活動簡述，例如：六月的婚禮外燴] 合作得很順利。這次的活動需求方便告訴我嗎？我直接根據上次的偏好幫您規劃。
```

**B2B / 長期合作：**
```
[公司名]您好，感謝您的合作邀約。

請問主要是什麼類型的活動？大概一年幾場次、每場人數範圍？

了解需求後我安排進一步洽談。
```

**規則：** 回頭客先查 TimeTree 歷史（請 A6 協助），帶入上次活動資訊。B2B 初步了解後轉 Owner 洽談。

## 摘要確認模板（資訊收齊，準備送報價）

**用時機：** 補問結束，準備整理送 A5 前，先與客戶確認

```
跟您確認一下：

活動日期：[日期]
人數：大人 [X] 位，小孩 [X] 位
活動類型：[類型]
場地：[描述]
[預算：[方向]（如有）]

我們會在 1–2 個工作天內提供菜單方案和報價，感謝您的耐心等候。
```

## 跟進提醒模板

```

**7 天報價跟進（客戶看了報價沒回應）：**
```
[名]您好，之前的報價不知道看過了嗎？菜色或預算需要調整都可以討論，檔期有限建議盡早確認。

## 客戶標籤說明

| 標籤 | 意思 | 下一步 |
|---|---|---|
| 🔴 急件 | 活動 7 天內 | 馬上轉給業務處理 |
| 🟠 報價中 | 資料齊全，送報價 | 等 A5 出報價單 |
| 🟡 補問中 | 資料不夠 | Q1 問，48h 後跟進 |
| 🟢 一般諮詢 | 純問問，沒要報價 | 回覆後不主動跟進 |
| 🔵 已報價待回覆 | 報價已送出 | 7 天後 Q8 跟進 |
| ⚪ 未成交 | 確定不做了 | 歸檔 |
| 🟣 回頭客 | 之前合作過 | 優先處理，查歷史 |
| ⚫ 轉真人 | 投訴/特殊/VIP | 轉給 Mina/Owner |
| 🟤 低於門檻 | 人數或金額不達標 | Q9 婉拒，導向外帶 |
