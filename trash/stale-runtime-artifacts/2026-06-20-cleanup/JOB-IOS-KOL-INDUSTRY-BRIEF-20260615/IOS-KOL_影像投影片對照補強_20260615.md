## 問題診斷

這次研究報告的主要缺口不是逐字稿品質，而是證據型態不完整。

影片型 KOL/研究員內容至少有三種訊號：

1. 音訊逐字稿：保留研究員口語重點、轉折、語氣、風險提醒。
2. 投影片畫面：保留表格、供應鏈 mapping、標的名稱、分類與主題邊界。
3. PDF/memo：保留長文邏輯、數字、段落結構與可回溯引用。

只用音訊會漏掉「畫面上有、講者不一定逐字念出」的資訊。這會讓整理結果變成主題摘要，而不是產業研究員的供應鏈拆解。

## 標的與受惠邏輯修正

### PCB/先進封裝設備

| 製程位置 | 投影片標的 | 為什麼受惠 | 推薦理由 |
| --- | --- | --- | --- |
| AOI 檢測 | 牧德 | EMIB、CoPoS、ABF/高階 PCB 線寬與良率要求提高，檢測需求隨製程複雜度上升。 | 受惠不是單純出貨量，而是高階板良率管理與檢測密度提升。 |
| 塗佈/烘烤/去膠渣 | 志聖 | 先進封裝與高階載板需要更穩定的材料塗佈、烘烤與去膠渣流程。 | 屬於製程升級型設備，若客戶 capex 往高階載板集中，設備規格與單價有機會同步提升。 |
| 濕製程 | 揚博 | 高階 PCB/載板層數與線路精細化拉高濕製程穩定性要求。 | 受惠於高階板製程站數增加與良率瓶頸。 |
| 鑽針 | 尖點 | 高階板孔徑、層數、精度要求增加，鑽針耗材價值與替換需求上升。 | 偏耗材/規格升級邏輯，和一次性設備 capex 不同，追蹤訂單延續性。 |
| 鑽孔設備 | 大量 | 先進封裝載板/PCB 鑽孔精度與產能需求提升。 | 偏設備擴產與高階鑽孔能力，需追蹤客戶擴產節奏。 |
| 塗佈/烘烤 | 群翊 | 高階 PCB 與載板流程中的塗佈/烘烤設備需求增加。 | 與志聖同站別但需分產品線與客戶結構，不能合併成同一投資理由。 |

## 新版取證流程

下次整理 KOL 影片時，不能以逐字稿直接定稿。必須建立 `slide_audio_alignment.csv` 或同等表格，欄位至少包含：

| 欄位 | 說明 |
| --- | --- |
| timestamp | 影片時間點。 |
| speaker | 講者，例如 Leo、Mark。 |
| slide_title | 投影片標題或右上主題。 |
| slide_text | OCR 或人工讀圖得到的完整表格/條列。 |
| transcript_summary | 同時間逐字稿摘要。 |
| pdf_match | 是否能在 PDF/memo 找到相同主題。 |
| extracted_companies | 影像或逐字稿出現的公司。 |
| second_layer_reason | 產業結構推論。 |
| third_layer_edge | call 公司、轉單、交期、驗證進度、BOM 變化等早期訊號。 |
| confidence | high / medium / low。 |
| action | 採用、待驗、修正原稿、刪除或降權。 |

## 衝突判斷規則

- 公司名稱、表格 mapping、製程站別：投影片優先。
- 口語 caveat、研究員語氣、風險提醒：逐字稿優先。
- 數字、長段落推演、完整主題結構：PDF/memo 優先。
- 官方規格、財報、公告、產能與營收事實：公開一手來源優先。
- 若四者衝突，不刪 edge；改用 `anomaly`、`company_call`、`public_compatible` 等標籤管理可信度。

## 對目前報告的直接優化

1. 將「PCB設備」從單一推薦主題拆成製程站別矩陣。
2. 將「功率元件」拆成 PMIC/DrMOS、Power MOSFET、Diode/TVS 三條投資邏輯。
3. 把立錡、力智列為 DrMOS 較直接標的；茂達、矽力-KY 列為後進/驗證追蹤。
4. 把富鼎從泛功率元件中拉出，標成 Infineon 替代與 Power MOSFET 對標邏輯。
5. 把台半、強茂、德微放在 Nexperia/禁令/TVS/Diode 轉單鏈，不與 PMIC 混在一起。

## 下次重跑建議

目前本機已有音訊與逐字稿；若要完整修正整份報告，下一步應下載完整影片，抽取投影片 frame，逐張建立 slide-audio alignment，再回寫 DOCX。

最低可行流程：

1. `yt-dlp` 下載完整影片。
2. `ffmpeg` 依 scene change 與固定秒數抽圖。
3. 對每張投影片做 OCR 或人工/vision 讀圖。
4. 用 whisper SRT 時間碼對齊投影片與口語內容。
5. 先更新標的矩陣，再更新摘要與推薦順位。

這樣可以克服「我聽到的重點」和「報告摘要」不一致的問題，因為所有結論都會回到同一張對照表，而不是只靠音訊或單一筆記。
