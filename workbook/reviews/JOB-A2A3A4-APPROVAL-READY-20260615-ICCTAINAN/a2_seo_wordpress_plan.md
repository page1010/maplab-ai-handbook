That supports a first-mover SEO page, with the caveat that CPC/volume still needs Keyword Planner or Google Ads read-only data.

## Draft Page Structure

1. Hero
   - H1 as above.
   - Short intro for meeting, exhibition, opening, briefing, and VIP reception use cases.
   - CTA: `說明活動日期、人數與場地區域，請 MAPLAB 協助整理餐點方向`.

2. Venue context
   - Mention 高鐵台南站旁, conference/exhibition setting, and organizer needs.
   - Link to official venue site as venue reference.

3. Case block
   - Public-safe heading: `大臺南會展中心企業會議茶點案例`
   - Internal evidence source: Drive folder title.
   - Copy should describe table layout, snack pickup rhythm, beverage flow, and meeting-break use.
   - Full institutional project name only after Owner approval.

4. Suitable event types
   - 工作會議 / 跨部會會議
   - 展覽接待 / VIP 點心吧
   - 開幕茶會 / 品牌發表
   - 招商說明會 / 研討會茶點

5. Menu and service style
   - Finger food.
   - Bite-size desserts.
   - Coffee / tea / cold beverage station.
   - Table setup, pickup route, replenishment rhythm.
   - Avoid price-first copy.

6. Venue logistics checklist
   - Floor / room / loading route.
   - Setup time.
   - Power and water needs.
   - Table count and placement.
   - Waste and teardown flow.

7. Internal links
   - `https://www.maplabkitchen.com/corporate-tea-party-desserts/`
   - `https://www.maplabkitchen.com/vip-expo-catering-business-meeting/`
   - `https://www.maplabkitchen.com/tainan-corporate-opening-tea-catering/`

8. FAQ
   - `大臺南會展中心活動可以安排外燴茶點嗎？`
   - `會議茶點和展覽接待餐點怎麼配置？`

## Page Checker Targets

Before publish approval:

- Title <= 60 Chinese characters and contains primary keyword.
- Meta description <= 155 Chinese characters and includes CTA intent.
- At least 3 FAQ items.
- All selected images have alt text.
- First 150 characters include `大臺南會展中心` and `外燴` or `茶點`.
- At least 2 internal links.
- CTA points to LINE.
- No price, internal date, local path, phone number from private source, or visible private meeting material.
