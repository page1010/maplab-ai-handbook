## 一、現行條文版本

報價單中存在**兩套條文版本**：個人客戶版 vs 公司行號版。

---

### 版本 A：個人客戶版（非正式）

出現形式較簡略，主要包含：

```
匯款資訊如下：
中國信託822 / 西台南分行
帳號：[收款資訊另提供]
戶名：[收款資訊另提供]
匯款後，再麻煩提供後五碼對帳。
如需收據請提前告知，當日會附上。

（1）已保留檔期，預約付訂後取消，欲收取訂金50%作為成本取消費
（2）用餐日期14天內取消（或變更），收取訂金80%作為食材成本取消費
（3）用餐當日取消（或變更），收取訂金100%作為取消與變更費
```

另有更簡化版：
```
訂金$[金額]，尾款$[金額]於活動日前匯款完成。
尾款活動「三日前」匯款完成（部分報價）
```

### 版本 B：公司行號版（正式合約）

```
▶簽約使用條款及細則：
（1）鑒於部分企業用戶之會計核銷，此合約僅供公司行號使用。
（2）本合約代表雙方對於___年___月___日之活動做出預約，並確認保留檔期。
（3）已保留之檔期，如有於十日內取消服務之情事，須支付活動合約總金額之20%材料損失費。
（4）活動當日取消（或臨時有地點、菜色、時間之變更），將酌情形額外收取費用。

‣活動指定地點如超過30分鐘距離須收取車馬費，諮詢依地區實際公里數各別報價。
‣擺設場地有樓層必須預先告知，2F以上無電梯須收取$1,000搬運費，有人協助收取$500元搬運費。
 若當日電梯因故無法使用，則現場以現金加收$1,000樓層搬運費。
```

變體版本（更嚴格）：
```
（4）活動當日取消或更動者，須支付總金額80%作為食材與人力成本賠償，恕不退還任何已付金額。
```

## 三、公司版 vs 個人版比較

| 項目 | 個人版 | 公司版 |
|------|--------|--------|
| 取消政策嚴格度 | 訂金 50/80/100% | 合約金額 20%（較寬）|
| 尾款時間 | 活動日前 / 三日前 | 活動日前匯款或當日現金 |
| 搬運費明定 | 無 | 有（2F $1,000 / 協助 $500）|
| 車馬費 | 通常加在備註 | 條文內明定 |
| 法律效力 | 低（口頭承諾居多）| 有合約形式 |
| 收據 / 發票 | 收據（個人）| 統編發票（公司戶）|

## 四、不一致問題（需修正）

### 問題 1：個人版取消條款較嚴，公司版反而較寬

- **個人版**：訂金 50% / 14天內 80% / 當日 100%
- **公司版**：合約金額 20%（十日內）/ 當日酌收
- 風險：大金額的公司訂單取消時損失較大，但保護力反而較弱

**建議**：公司版加入分層取消費率（如 14 天內 30%、7 天內 50%、當日 80%）

### 問題 2：尾款時間說法不一

- 「活動日前」（模糊）
- 「活動三日前」（有明定）
- 「點交餐檯後匯款」（現場付）

**建議**：統一為「活動前 3 個工作日內匯款完成，或活動當日點交後 30 分鐘內匯款」

### 問題 3：搬運費金額個人版沒明定

部分個人版報價遇到 2F 才臨時加收，容易有爭議。

**建議**：所有版本統一加入搬運費說明

### 問題 4：統編 / 發票缺乏標準流程

共 12 份報價提到統編，但無標準格式，都是手動備註。

**建議**：建立公司版報價單模板，含統編欄位與發票類型選項（電子發票 / 統一發票）

## 五、建議標準條文（修正版）

### 個人版（簡化）

```
【付款方式】
訂金 $___，尾款 $___，請於活動前 3 個工作日完成匯款。
匯款完成後請提供後五碼對帳，如需收據請於活動前 3 天告知。

【取消政策】
（1）預約付訂後取消：訂金 50% 作為食材成本取消費
（2）活動 14 天前取消：訂金 80% 作為食材成本取消費
（3）活動當日取消（或變更）：訂金 100% 不予退還

【服務附加費用】
‧超過 30 分鐘車程須收取車馬費（依公里數報價）
‧場地 2F 以上無電梯：加收 $800 搬運費；有人協助：$500
```

### 公司版（正式合約）

```
▶簽約使用條款及細則（公司行號）
（1）本合約僅供公司行號使用，適用統一發票開立。
（2）本合約代表雙方確認保留___年___月___日之活動檔期。
（3）取消政策：
    • 活動 14 天以上前取消：合約金額 20%
    • 活動 7~14 天前取消：合約金額 50%
    • 活動 7 天內取消：合約金額 80%
    • 活動當日取消：合約金額 100%，恕不退還
（4）臨時變更地點、菜色、時間，須提前 48 小時通知，否則依取消政策計費。

‣車馬費：超過 30 分鐘車程依實際公里數另計。
‣搬運費：2F 以上無電梯 $1,000；有人協助 $500；當日電梯故障加收 $1,000。
```
