# 外燴品牌廣告文案複審 — 給 GPT 的作業說明(2026-09-30)

## 你的角色

台南一家外燴品牌(MAPLAB Kitchen,西式派對外燴,服務台南/嘉義/高雄)的廣告文案第二意見。
下面有 56 則正在跑或待上線的廣告文案。請逐則判斷,並依最後一節的格式回覆。

背景規則(公開可讀,選讀):
https://raw.githubusercontent.com/page1010/maplab-ai-handbook/main/docs/OPERATING_CULTURE.md

## 品牌口氣鐵律(這是判斷基準,比你的通用文案直覺優先)

1. **講「我們接手什麼」,不講「客人缺什麼」。**
   ✅ 你安心接待,餐點我來 / 甜點桌交給我們
   ❌ 你一定很忙吧 / 媽媽總是最後一個吃飯的人 / 你是不是還在煩惱
   理由:把客人寫成匱乏、狼狽、忙到沒空的人,是冒犯,不是共鳴。

2. **不准把工作丟回客人。** 不要寫「先想好人數」「記得提前告知」這類把待辦推給客人的句子。

3. **不指名職務。** 不要出現「行政窗口」「HR」「秘書」這種指定誰該來談的字。

4. **禁用語(直接違規):** 保證、超值、CP值爆高、趕快預約、名額有限、限時優惠、賓主盡歡、賓至如歸、賓客絡繹不絕、琳瑯滿目、動線。

5. **不准寫做不到的承諾。** 不要出現具體時效(24小時內回覆)、低消、最低消費、幾人起訂、提前X天這類營運門檻——這些數字沒有經過確認,寫了就是編造。

6. **不准編營運事實。** 價格、人數門檻、服務範圍,沒有出處就不要寫。

7. **每一句都要有主體。** 整段話裡要看得出來是在對「來看廣告的那個人」說話,或在講「我們會做什麼」。兩者皆無 = 空話。

8. **AI 感的判準是可替換性測試。** 把品牌名換成任何一家同業,句子照樣成立 → 這句等於沒講。
   例:「以美感 × 節奏打造專屬外燴體驗」「每一桌都是故事的延伸」= 典型空話,要打掉。

## 你要做的事

對 56 則的每一則:
- 判定 **保留 / 微調 / 重寫**
- 只有 微調 和 重寫 才需要給新字
- 新字必須同時滿足上面 8 條
- 新字長度盡量不超過原字

## 回覆格式(務必嚴格照做,這份會被程式讀進試算表)

只輸出一個 TSV 區塊,不要前言、不要結語、不要 markdown 表格、不要程式碼區塊標記。
第一列是表頭,欄位固定六欄、以 tab 分隔:

編號	判定	建議新字	命中哪一條鐵律	為什麼	信心

- `編號` = 原始編號,不可改、不可跳號、56 則全要有一列
- `判定` = 只能填 保留 / 微調 / 重寫 三者之一
- `建議新字` = 判定為保留時填 `-`
- `命中哪一條鐵律` = 填上面 1~8 的編號,多條用逗號;保留時填 `-`
- `為什麼` = 一句話,20 字以內
- `信心` = 高 / 中 / 低

最後另起一行,輸出一行總結,格式固定:
SUMMARY	保留=<數字>	微調=<數字>	重寫=<數字>
