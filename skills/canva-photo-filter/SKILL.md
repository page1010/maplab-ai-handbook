# Skill: canva-photo-filter — MAPLAB 品牌照片濾鏡 SOP

## 觸發條件
- 任何用 Canva 編輯品項照片、活動照片、廣告素材的任務
- 上傳新照片到 Items K 欄前（image_url）
- 製作 Slide Menu Showcase 圖片前
- 拍完照片需要統一色調前

## 為什麼要做這個
- 統一品牌視覺：自然、溫暖、安靜、細緻、不浮誇
- 避免每張照片色調不一致破壞品牌感
- generateProposal_v2.gs 把這些照片插入 Slide 時需要統一比例 + 色調

- skills/maplab-visual-spec.md（完整品牌視覺規範）
- skills/brand-voice-guide.md（品牌語氣，視覺要對應）

## 二、Canva 照片濾鏡參數（依 visual-spec v1）

打開 Canva → 上傳照片 → 點「調整」面板 → 按以下數值套用：

### 曝光與色調
| Canva 欄位 | 數值範圍 | 對應 visual-spec |
|-----------|---------|-----------------|
| 亮度 Brightness | +5 ~ +12 | 曝光 +0.3 ~ +0.7 EV |
| 對比 Contrast | -10 ~ -15 | 對比 -10 ~ -15 |
| 高光 Highlights | -20 ~ -30 | 高光 -20 ~ -30 |
| 陰影 Shadows | +10 ~ +20 | 陰影 +10 ~ +20 |
| 色溫 Temperature | +5 ~ +10（暖） | 5500–6500K |
| 色調 Tint | 0 ~ +3（微粉） | — |

### HSL 微調（食物色相）
| 顏色 | 飽和度 | 明度 | 適用品項 |
|------|-------|------|---------|
| 橙/黃 | +10 ~ +15 | +5 | 烤物、起司、麵包、咖哩 |
| 綠 | +5 ~ +10 | 0 | 沙拉、香草、蔬菜 |
| 紅/粉 | +5 | 0 | 莓果、肉類、甜點 |
| 藍 | -10 | 0 | 桌布、餐具、背景去冷調 |

### 銳利度
- 銳利化 Sharpness：+5 ~ +10（不要超過 +15，會顯得粗糙）

## 三、Canva 操作步驟（一張照片完整流程）

1. 打開 Canva → 建立設計 → 自訂尺寸 **800 × 420 px**（這是 Slide Menu Showcase 的圖片尺寸）
2. 上傳照片 → 拖到畫布
3. 雙擊照片 → 拖動裁切焦點對準食物主體
4. 點「調整」面板 → 套用上面的數值
5. HSL 微調（依品項色相主色）
6. 檢查：照片色溫是否融入品牌奶油白/暖米背景？如果太冷，色溫再 +2~3
7. 下載：JPG 格式，品質 80%
8. 命名：`{item_id}_{中文品名}.jpg`（例如 `APP004_明太子可頌.jpg`）
9. 上傳到 Drive `MAPLAB_Items_Photos` 資料夾（ID: 1Z62HUIiVutGNqLJMGyTfBCZ-D5g2vnOT）
10. 複製 Drive 連結 → 更新 Items 表 K 欄 image_url

## 四、檢查清單（送出前自檢）

- [ ] 尺寸 800×420 px（1.9:1 比例）
- [ ] 食物在畫面中心或黃金分割點
- [ ] 色調偏暖（不要冷藍）
- [ ] 高光不過曝（白色食物有層次）
- [ ] 陰影有細節（不死黑）
- [ ] 飽和度自然（不像 Instagram 濃鮮）
- [ ] 整體色感能跟奶油白 #FAF7F2 背景融合
- [ ] 檔名格式正確
- [ ] 已上傳 Drive
- [ ] Items K 欄已更新

## 五、常見錯誤

1. **色溫太冷** — 拍攝環境是日光燈時很容易冷藍。一定要 +5 以上
2. **對比拉太高** — 食物會變硬。維持 -10~-15
3. **飽和度爆開** — 看起來很假。HSL 用 +5~+15 範圍，不要 +30
4. **沒裁切就上傳** — Slide 框框是 1.9:1，拍直幅或方形會被擠壓
5. **檔名隨便** — 系統要靠檔名 match item_id，不能用 IMG_1234.jpg

## 六、批次處理建議
如果有 10+ 張照片要套同樣濾鏡：
1. 在 Canva 把第一張調好
2. 右鍵 → 「複製樣式」
3. 上傳其他照片 → 「貼上樣式」
4. 個別微調 HSL
