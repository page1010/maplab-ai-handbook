## 欄位結構（2026-03-31 確認版）

```
F 欄：數量（業務填）
G 欄：單位成本（VLOOKUP Items!C:E,3 = default_cost）
H 欄：成本小計（=G*F）
E 欄（匯總區）：金額
I 欄：業務報價(單價)（業務填，不走公式）
```

### 關鍵公式

| 儲存格 | 公式 | 說明 |
|--------|------|------|
| G7:G19 | `=IF(D7="","",IFERROR(VLOOKUP(D7,Items!C:E,3,0),"N/A"))` | 查品項成本 |
| H7:H19 | `=IF(D7="","",IFERROR(G7*IF(F7="",1,F7),""))` | 成本*數量 |
| E25 | `=SUM(H7:H19)` | 餐點總成本 |
| E26 | `=IF(D26="否",0,IF(E33=0,"",E33*0.1))` | 10%服務費（連動E33） |
| G32 | `=SUM(E25:E32)` | 報價費用加總 |
| H32 | `=SUM(H7:H19)` | 品項原料總成本 |
| H33 | `=H32` | 訂單成本 |
| H34 | `=IF(E33=0,"",TEXT((E33-H33)/E33,"0.0%"))` | 毛利率 |
| **E33** | 業務手填 | **業務報價總額（核心輸入點）** |

### 業務使用流程
1. D 欄下拉選品項名稱
2. F 欄填數量
3. G 欄自動帶出單位成本，H 欄自動算成本小計
4. E25 自動加總餐點成本
5. E26 服務費連動 E33（業務填完總額後自動算）
6. E28/E30 長桌費/車馬費手填或下拉
7. **E33 業務填入報價總額**（唯一需要人工填的金額）
8. H33 訂單成本 + H34 毛利率自動顯示

## 踩過的坑

1. **E25 公式歷史問題**：曾用 SUMPRODUCT 查 I 欄，但 I 欄是業務手填的報價單價非成本，導致 E25=0。正確做法是 `=SUM(H7:H19)`。
2. **H33 邏輯錯誤**：原公式 `=H32+G32` 把報價加總加進成本，導致毛利率偏低（50.4%）。修正為 `=H32` 後毛利率正確（80.2%）。
3. **G 欄查 cost 不是 price**：Items.D default_price 全空，G 欄用 `Items!C:E,3` 查 cost 是唯一有效路徑。
4. **服務費連動 E33**：E26 用 `E33*0.1`，業務必須先填 E33 才能看到正確服務費。
5. **04-08 e2e 大修**：QuoteForm 欄位 id 改過但 Code.gs 沒跟，導致 `new Date(undefined)` 每次都爆。E2/E3 是 label 不是 value（C/E 整欄是 label，D/F 才是 value）。
