## QA-1：個人週歲 20 人 $15K 輕食 A ✅

### Input（Mina 告訴你）

> 報價 李晴宜 週歲抓周 20人 15000含10%服務費 12/21 上午11點 台南安南區安和路三段190巷 室內冷氣房 自家畫廊 不要羊 部分長輩不吃牛串燒可以 輕食A

### 你的判斷

| 判斷項 | 結果 |
|--------|------|
| 活動類型 | 個人 → `to_c` |
| 餐點形式 | A 輕食茶點 |
| Skeleton | 3 鹹 + 2 開胃 + 3 甜 + 1 飲 = **8 品** |
| 價位區間 | $15K-$24K（客戶選 $15K+10% = $16,500） |
| 車馬費 | Maps 查安南區 → 導航 < 30 分鐘 → **$0** |
| 搬運費 | 一樓 → **$0** |
| 訂金 | 個人 baseline **$3,000** |
| 低消檢查 | $15K > $10K → ✓ |
| 超時檢查 | 活動時長未明，假設 3hr 內 → ✓ |
| 飲食禁忌 | 不要羊（硬禁）/ 部分長輩不吃牛（軟禁）/ 串燒可以（例外） |
| 特殊場地 | 自家畫廊（佈置需跟場地風格搭配） |

### 你的操作步驟

1. 組 formData：`{ customer: '李晴宜', date: '2025-12-21', time: '11:00', address: '台南市安南區安和路三段190巷71弄17號', eventType: '生日派對', headcount: '20', depositAmount: '3000', dietaryNotes: '不要羊 部分長輩不吃牛 串燒可以', floorFeeMode: 'none' }`
2. 呼叫 `createQuote(formData)` → 拿到 URL
3. 開 copy → D7~D14 填 8 個品項（依 skeleton 3+2+3+1）
4. 每品數量 15-20
5. 算成本 → 驗毛利率 ≥ 70%（$15K × 30% = $4,500 成本上限）
6. 回 Mina：URL + 摘要

### 真實報價參考（📐 2025/1/11 陳瀅如 週歲 20 人 $16,500）

- 5 鹹食 + 3 甜點 + 6L 黃金蕎麥
- 餐點 $15,000 + 10% 服務費 $1,500 + 2F 搬運費 $1,000 → 總 $17,500
- Discount $16,500（合作廠商搬運費折抵）
- 訂金 $3,000 / 尾款 $13,500
- 一次性餐具 20 組 + 打包盒 10 個

## QA-3：企業開幕 低預算 長時間 📐

### Input

> 報價 Gina浥慧 企業開幕 30-40人 12000 11/9 早上十點到下午五點 安平區慶平路440號 室內一樓 茶點為主

### 你的判斷

| 判斷項 | 結果 |
|--------|------|
| 活動類型 | 企業（開幕 = 企業關鍵字）→ `to_b_deposit` |
| ⚠️ 低消 | $12K > $10K → ✓ 但偏低，標準茶點最低約 $12K |
| ⚠️ 超時 | 10:00-17:00 = **7 小時 > 3 小時** → alert Mina |
| Skeleton | 茶點版：3 鹹 + 2 開胃 + 4 甜 + 1 飲 ≈ 9 品 |
| 服務費 | B2B 全包（已含，不顯示 10% 行） |
| 車馬費 | 安平區 < 30 分 → $0 |

### 你的操作

1. **先 alert Mina**：「活動 7 小時超過標準 3 小時撤場，要加超時費嗎？」
2. Mina 確認後 → createQuote
3. 品項策略：$12K 預算 → 最大化數量（135 件），選成本最低品項
4. 條款 to_b_deposit + 公司帳戶

### 真實報價參考（📐 2025/2/15 孫歆程 開幕 50/25 人 $20,000）

- 規劃 50 人 / 提供份數 25 人
- 5 鹹食 + 4 甜點 + 6L 飲品兩款
- 餐點 $20,000（已含服務費）
- 訂金 $3,000 / 尾款 $17,000

## QA-4：外帶自取（非外燴，完全不同 flow）✅

### Input

> 外帶 范純禎 11/29 下午兩點半 她自己會叫Lalamove來拿 漢堡排45入 蛋沙拉可頌60入 鹹派3個切8 小圓鬆餅120顆 烤布丁60個 她算15885

### 你的判斷

| 判斷項 | 結果 |
|--------|------|
| 類型 | **外帶自取** — 不走 createQuote！ |
| 品項 | 客戶自己選好了 |
| 金額 | 客戶自己算好了 $15,885 |
| 你要做的 | 確認品項有貨 + 驗算金額 + 收訂金 + 列確認單 |
| 車馬費 | 不適用（客戶自己 Lalamove 取） |
| 搬運費 | 不適用 |

### 你的操作

1. **不呼叫 createQuote** — 外帶不是外燴
2. 查 Items 表確認 5 個品項都有
3. 加總驗算 $15,885 ✓
4. 回 Mina：「外帶確認：5 品 $15,885，品項都有，取餐 11/29 14:30。訂金建議 $5,885（尾款 $10,000 取整）。」
5. Mina 確認 → 列確認單 + 匯款資訊（**個人帳戶 莊貴棻**）

### 真實結果（✅ 范純禎 $15,885）

- Mina 確認單原文：「1.招牌手拍漢堡排起司小漢堡(豬)×45入 2.日式經典蛋沙拉可頌×60入 3.花椰蘑菇鹹派×3個(都切8) 4.荷蘭小圓鬆餅×120顆 5.法式焦糖烤布丁×60個」
- 訂金 $5,885 / 尾款 $10,000（或付清）
- 客戶後來還問了飲品桶 → 最後沒加

## QA-7：企業首詢但未成交（處理方式）📐

### Input

Mina 沒說話。LINE webhook 收到立碩車業-葉汶按了 #4，填了企業版表單。但之後沒下文。

### 你的判斷

| 判斷項 | 結果 |
|--------|------|
| 狀態 | 客戶只填了表單，沒確認預算 |
| 你要做什麼 | **先不動**。等 Mina 回覆客戶後再看是否需要產報價 |
| 不做什麼 | 不自動產報價（沒有預算確認 = 沒有觸發條件） |

### 觸發條件

只有以下情況才產報價：
1. Mina 明確說「幫我報價 [客戶] [預算]」
2. 或 Mina 轉述客戶確認的預算
3. **客戶只填表單不算觸發** — 等 Mina 判斷
