## 1. 排名位置怎麼看

### 1.1 排名區間定義

| 排名區間 | 意義 | 對流量的影響 | 行動建議 |
|---------|------|-----------|---------|
| Top 3（1-3 名） | 黃金位置，獲得 60%+ 點擊 | 極高流量 | 守住：持續更新內容、增加內連 |
| 4-10 名 | 第一頁，有穩定曝光 | 中等流量 | 衝刺：優化 Title/Meta、補內連、加 FAQ schema |
| 11-20 名 | 第二頁，幾乎沒點擊 | 極低流量 | 重點攻擊：這些是 ROI 最高的優化目標 |
| 21-50 名 | Google 認識你但不信任你 | 接近零 | 長期養：增加相關內容、外連、內連 |
| 51-100 名 | 剛進入雷達 | 零 | 觀察：可能是新文章，給時間 |
| 100+ 名 | 未排名 | 零 | 檢查：是否有索引問題、內容品質問題 |

### 1.2 MAPLAB 目標參考值

以台南外燴產業來說（地區性服務業、中低競爭度）：

|------|-------------------|-----------------|-----------------|
| Top 3 關鍵字 | 21 | 30+ | 50+ |
| 4-10 名關鍵字 | 16 | 25+ | 40+ |
| 總關鍵字數 | 297 | 400+ | 600+ |

## 2. 指標怎麼判讀

### 2.1 Search Traffic（搜尋流量）

這是最終結果指標。

| 變化 | 判讀 | 行動 |
|------|------|------|
| ▲ 上升 | SEO 正在起作用 | 繼續目前策略，記錄什麼有效 |
| ▼ 下降但 Impressions 上升 | 排名進步但標題不吸引人 | 優化 Title / Meta Description |
| ▼ 下降且 Impressions 下降 | 排名退步 | 檢查是否有演算法更新、內容被取代 |
| ➡️ 持平 | 成長停滯 | 需要新內容或新關鍵字策略 |

### 2.2 Impressions（曝光數）

代表 Google 認為你和這些搜尋相關。

| 變化 | 判讀 |
|------|------|
| ▲ 大幅上升 | 新內容開始被 Google 收錄、排名提升 |
| ▲ 上升但 Clicks 下降 | 排名在第二頁邊緣（曝光但沒人點） |
| ▼ 下降 | 排名退步或搜尋需求季節性下降 |

### 2.3 CTR（點擊率）

直接反映標題和描述的吸引力。

| CTR 範圍 | 判讀 | 行動 |
|---------|------|------|
| > 5% | 優秀 | 維持 |
| 3-5% | 正常 | 可優化 Title/Description |
| 1-3% | 偏低 | 需要改寫標題、加入數字/問句/地區詞 |
| < 1% | 很差 | 可能排名太後面，或標題完全不吸引人 |

### 2.4 Average Position（平均排名）

| 位置 | 判讀 |
|------|------|
| < 5 | 很好，在第一頁上半部 |
| 5-10 | 還行，在第一頁 |
| 10-20 | 關鍵轉折點：從這裡推進到第一頁 ROI 最高 |
| 20-50 | 有潛力但需要大量優化 |
| > 50 | 基本上是沒排名 |

## 3. SEO 分數怎麼解讀

Rank Math SEO Score 是文章的「技術健康度」，不是排名保證。

| 分數 | 等級 | 意義 | 行動 |
|------|------|------|------|
| 81-100 | Good（綠色） | 技術面完善 | 不需改動，專注內容品質 |
| 51-80 | Fair（橙色） | 有改善空間 | 檢查 Focus Keyword、內連、圖片 alt |
| 0-50 | Poor（紅色） | 技術問題多 | 優先修復：缺 Focus Keyword、標題太長/太短 |
| N/A | No Data | 未設定 SEO | 立即設定 Focus Keyword 和 Meta |

### MAPLAB 現況問題

目前 Good=2 / Fair=54 / Poor=6，代表：
- 54 篇文章技術上「還行」但沒有達到最佳化
- 最常見問題是 Focus Keyword 和文章內容不一致（批次生成的文章）
- 建議：從 Poor 的 6 篇開始修，再逐步把 Fair 升級到 Good

## 4. 索引狀態怎麼看

| 狀態 | 意義 | 行動 |
|------|------|------|
| 已索引（Pass） | Google 已收錄，可出現在搜尋結果 | 正常，無需動作 |
| 找到-未索引 | Google 知道但覺得不值得收錄 | 檢查內容品質、是否重複、加內連引導 |
| 重新導向 | URL 有 301/302 跳轉 | 確認跳轉是否正確，清理不必要的跳轉 |
| 無法辨識 | Google 無法正確解析 URL | 檢查 robots.txt、sitemap、頁面結構 |
| Excluded | 被排除（noindex 或低品質） | 確認是否故意排除，否則修復 |

### MAPLAB 索引健康度判讀

| 指標 | 健康 | 警告 | 危險 |
|------|------|------|------|
| 索引率 | > 85% | 70-85% | < 70% |
| 找到未索引 | < 5% | 5-15% | > 15% |
| 無法辨識 | 0 | 1-2 | > 3 |

目前 70% 索引率 = ⚠️ 警告等級，需要改善。

## 5. 優化優先順序決策框架

當有多個問題要修時，按這個順序：

### 優先級 1：技術問題（擋住成長的）
- 未索引的頁面 → 提交 sitemap、加內連
- Poor SEO score 的文章 → 修 Focus Keyword
- 404 錯誤 → 設定 redirect

### 優先級 2：快速見效（低成本高回報）
- 排名 11-20 的關鍵字 → 這些最接近第一頁，優化後 ROI 最高
- CTR 偏低的高曝光頁面 → 改標題就能增加點擊
- Focus Keyword 不匹配 → 批次修正

### 優先級 3：內容補強
- 缺少的關鍵字主題頁 → 建新的 Landing Page
- 文章間缺少內連 → 加入相關文章連結
- Schema 標記 → FAQ / Service / LocalBusiness

### 優先級 4：長期經營
- 外連建設
- 新主題擴展
- 季節性內容策略
