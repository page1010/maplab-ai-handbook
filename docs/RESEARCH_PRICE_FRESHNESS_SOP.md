# 查價與研究資料新鮮度 SOP(所有研究 agent 必讀)

- 建立:2026-08-24|起因:Owner 指正 08/24 航運報告引用 08/17 舊股價、且盤後交付卻無當日收盤價
- 適用:任何含「價格/指數/報價」的研究報告、盯盤訊息、群組回交
- 地位:交付前的硬性檢查閘(gate),不是建議

---

## 一、鐵律五條

1. **價格必須來自官方/即時 API,不得來自新聞文章。**
   新聞裡的價格是「事件當天」的價格,一律視為過期背景,只能描述事件,不能當現價。
   台股上市:TWSE MIS 即時 API(見下方腳本);上櫃:TPEx OpenAPI;盤後日線:TWSE `STOCK_DAY_ALL`。
   美股/期權/加密:futuapi skill(富途 OpenD)。

2. **每一個數字旁邊必須標資料日期。**
   寫「長榮 232(08/17 盤中)」可以;寫「長榮 232」不可以。
   摘要壓縮時日期標記不得被壓掉——摘要裡的價格如果沒有日期,讀者一定當成現價。

3. **交易日 14:00 後交付的報告,必須含當日 13:30 官方收盤價。**
   標題含「追蹤/報價/盯盤」的產出,缺當日收盤 = 未完成,不得交付。
   非交易日交付,標明「最近交易日 MM/DD 收盤」。

4. **分辨指標的發布頻率,標「發布值」而非「今日值」。**
   - SCFI/CCFI:每週五發布(週級)→ 寫「08/21 發布值」
   - BDI:每交易日發布 → 查最新一日
   - 台股:每交易日 13:30 收盤
   - 財報/月營收:標會計期間+公告日

5. **上市狀態/代碼/掛牌先查再答。**
   模型知識庫裡的掛牌狀態一律過期(SKHY 教訓:2026-07 已上 Nasdaq,知識庫還停在 OTC)。

## 二、交付前檢查清單(執筆 agent 自查,派工方抽查)

- [ ] 報告尾附「資料時戳表」:關鍵數字 → 來源 → 資料日期
- [ ] 今天是交易日且現在 > 14:00?→ 當日收盤價已入報告
- [ ] 摘要版(Telegram/群組)逐條檢查:每個價格帶日期
- [ ] 週級指標(SCFI 等)標「MM/DD 發布」
- [ ] 觸發條件裡的價位,和當日現價的距離已交代(例:SCFI 3,409 vs 觸發 3,200,緩衝 6%)

## 三、標準查價工具

```
bash scripts/twse_quote.sh 2392 2603 2609        # 台股上市即時/收盤(TWSE MIS)
```

輸出含 code/名稱/最新價/漲跌/日期/時間,日期欄就是資料日期,直接抄進時戳表。
上櫃股改用 `otc_` 前綴(腳本內建說明)。美股與其他資產走 futuapi skill。

## 四、派工方(A0/Codex)責任

- 派工卡必須寫明「交付含當日收盤,照 RESEARCH_PRICE_FRESHNESS_SOP」
- 回交群組/Owner 前,派工方用 twse_quote.sh 抽核至少 2 個關鍵價格,不符退回
- 違例處理:發現過期價格已送出 → 24 小時內主動更正,不等 Owner 指出
