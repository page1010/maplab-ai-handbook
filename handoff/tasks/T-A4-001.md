                ## ⛔ GPS 細分技術問題說明（S5.5 / S6.5 全部年份適用）

                ### 問題根本原因

                GPS 細分的資料來源是 **Google Photos Takeout 的 JSON sidecar 檔**。每張照片有一個對應的 `.json` 檔，內含拍攝地點座標：

                ```
                IMG_20220101_120000.jpg      ← 圖片（已上傳 Drive）
                IMG_20220101_120000.jpg.json ← GPS metadata（★ 沒有上傳 Drive）
                ```

                ### 為什麼 JSON 沒有上傳？

                Owner 執行 Google Photos Takeout 時，只把**照片本身（.jpg/.mp4）**上傳到 Google Drive。Takeout 壓縮包裡的 `.json` sidecar 檔**沒有一起上傳**。

                ### Colab 實際執行結果

                ```
                S5.5 GPS cell 執行輸出：
                JSON map built: 0 files ← Drive 裡找不到任何 .json 檔
                ```

                ### ✅ 確認採用方案 C：EXIF 讀取

                **原理**：圖片本身的 EXIF metadata 也有 GPS 座標，用 Python `PIL/Pillow` + `piexif` 直接讀圖。不需要上傳任何 JSON，資料已在 Drive 的圖片裡。

                **可行性評估**：
                - 圖片通常保留 EXIF（特別是手機拍攝的）
                - - 部分照片可能被 Google 清除 EXIF（分享時）
                  - - 預估覆蓋率：70-80%（剩下標 no_gps，可接受）
                    - - 需先安裝：`pip install piexif`（PIL 已內建）
                     
                      - **EXIF GPS 讀取程式碼（替換舊的 JSON 讀取）**：
                     
                      - ```python
                        import piexif
                        from PIL import Image
                        import io

                        def get_gps_from_exif(img_bytes):
                            """從圖片 EXIF 讀取 GPS 座標，回傳 (lat, lon) 或 (None, None)"""
                            try:
                                img = Image.open(io.BytesIO(img_bytes))
                                exif_data = piexif.load(img.info.get('exif', b''))
                                gps = exif_data.get('GPS', {})
                                if not gps:
                                    return None, None
                                def to_degrees(value):
                                    d, m, s = value
                                    return d[0]/d[1] + m[0]/m[1]/60 + s[0]/s[1]/3600
                                lat = to_degrees(gps[piexif.GPSIFD.GPSLatitude])
                                if gps[piexif.GPSIFD.GPSLatitudeRef] == b'S':
                                    lat = -lat
                                lon = to_degrees(gps[piexif.GPSIFD.GPSLongitude])
                                if gps[piexif.GPSIFD.GPSLongitudeRef] == b'W':
                                    lon = -lon
                                return lat, lon
                            except:
                                return None, None
                        ```

                        **注意**：需要下載照片本體（每張約 3-5MB），速率會比主分類慢（約 100-200 張/h）。先用 30 張測試覆蓋率，再決定是否跑全量。
