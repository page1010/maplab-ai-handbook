function doPost(e) {

      if (event.type === 'message' && event.message.type === 'text') {

  if (!sheet) {

- Header 是：`msg_id | case_id | timestamp | speaker | message | source`
- 實際寫入只有 4 欄：`timestamp | userID | message | LINE`
- 資料塞進前 4 欄，msg_id / case_id 那兩欄完全空著

**2. 大量重複資料**
- 同一則訊息出現 2-3 次（pending queue 被多個 trigger 重複處理）
- 這是之前觸發器累積的後遺症，已沖出來的 pending 資料重複執行了
