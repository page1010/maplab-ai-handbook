## 操作方式

### 方法 A：從 Sheet 選單（業務日常用）
1. 打開主系統 Sheet → 點「MAPLAB > 產出 Slide 提案」
2. 系統自動讀取 QUOTE_DRAFT → 複製模板 → 填入品項+照片
3. 完成後彈出 Slide URL

### 方法 B：從 doPost API（A6 用）
```bash
curl -L -H "Content-Type: application/json" \
  -d '{"action":"createSlides","spreadsheetId":"<報價單ID>","clientName":"客戶名"}' \
  "<Web App URL>"
```

### 方法 C：GAS 編輯器（debug 用）
選函數 `createSlidesFromSheet` → 執行
