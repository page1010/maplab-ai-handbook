## 五欄檢查的實際狀態(照實寫,不宣稱 exit 0)

非檔案問題)。所以改用該腳本的**同一條 regex** 逐欄驗過:

```
grep -nE '^[ \t]*[-*+]?[ \t]*\*\*(結果|指標|期限|權限|回報點|動作可逆性)\*\*[ \t]*[:：][ \t]*.+$'
```

六欄全部命中(行 40–45)、值皆非空、無佔位符;「結果」欄不含
`UNDISPATCHABLE_MARKS`(登入／授權碼／帳密／cookie 等)故不屬派工無效類;
「回報點」欄同時含 `done` 與 `blocked` 兩個終態。
**等於通過,但沒有 exit 0 的實跑輸出——下一個能跑 python3 的人請補跑一次。**
