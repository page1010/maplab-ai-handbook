## Step by Step 操作手冊

### 前置條件
- GAS 已部署最新版本（含 createSlides.gs）
- appsscript.json 已加入 presentations scope
- Owner 已在 GAS 編輯器跑過一次 createSlidesFromSheet() 觸發授權同意

### 方法 A：從 Sheet 選單觸發
1. 打開主系統 Sheet（MAPLAB_外燴系統_v0.1）
2. 點選單「MAPLAB > 產出 Slide 提案」
3. 系統自動讀取 QUOTE_DRAFT 裡的品項，複製 Slide 模板，填入品項名稱和照片
4. 完成後彈出 Slide URL

### 方法 B：從 doPost API 觸發（A6 用）
1. 先跑 createQuote 拿到報價單 spreadsheetId
2. POST createSlides：
```bash
curl -L \
  -H "Content-Type: application/json" \
  -d '{"action":"createSlides","spreadsheetId":"<報價單ID>","clientName":"客戶名"}' \
  "<Web App URL>"
```
3. 回傳 {"success": true, "slideUrl": "https://..."}

### 方法 C：從 GAS 編輯器手動跑（debug 用）
1. 打開 GAS 編輯器
2. 選函數 createSlidesFromSheet
3. 點「執行」
4. 看執行紀錄確認結果
