# MAPLAB OpenClaw Safety Boundaries

## Non-negotiables
- OpenClaw gateway stays loopback-only unless the owner explicitly changes it.
- Google Drive access is limited to the dedicated MAPLAB workspace folder.
- GitHub writes happen only on branches, never directly to `main`.
- WordPress first-stage output is draft only.
- Meta ads first-stage output is creative only.
- Stock assistant first-stage output is research only.
- Deletes, overwrites, mass moves, new skill installs, `.env` reads, API key reads, main pushes, publishing, and ad launches require human confirmation.

## Review rule
- Every risky run leaves a bundle in `workbook/reviews/JOB-xxx/`.
