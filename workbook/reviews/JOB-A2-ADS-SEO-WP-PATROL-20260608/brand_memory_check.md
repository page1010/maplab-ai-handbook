# Brand Memory Check — A2 Ads / SEO / WordPress Patrol

Date: 2026-06-08
Role: A2 Ads SEO WordPress Patrol
Mode: read-only patrol + repo-only reporting

## 1) MAPLAB Brand Value

MAPLAB 的核心價值是自然、溫暖、安靜、細緻、有質感、專業、穩定、有分寸。它賣的不是低價，而是把活動場景、餐點品質、取用節奏、體面與畫面感整理成可交付的款待成果。

## 2) MAPLAB Brand Voice

來源：`skills/brand-voice-guide.md`

- 說場景，不硬講賣點。
- 用具體名詞，不用空泛形容。
- 保持穩定、開放、有邏輯，不把話說死。
- 禁用強推銷、誇張促銷、說服式對比句型。
- B2B 文案要讓窗口覺得好交代、可信任，不是被教育或被催單。

## 4) Live Website State Source

live state 來源層級：
1. live URL HTTP 狀態與前台頁面
2. WordPress public REST / wp-admin read-only evidence
3. Owner Chrome read-only visual bridge（WordPress / Google Ads / Meta Ads）
4. repo 文件只作輔助，不取代 live 證據

本輪沒有新增 live HTTP 或 authenticated UI 重播，因此今天沿用的外部狀態都必須標示來源日期。

## 5) Shared MAPLAB + Investment OS Culture Rules

- `VERIFIED`：有可回放的檔案、畫面、UI packet 或狀態紀錄。
- `REASONABLE INFERENCE`：由已驗證證據推出的合理結論，不包裝成現況事實。
- `MISSING DATA`：缺新鮮證據就直接寫缺口，不補猜。
- `APPROVAL BOUNDARY`：不可發布 WordPress、不可改 Google Ads / Meta Ads、不可碰 Rank Math 付費/設定狀態、不可讀 secrets/cookies。
- `HANDOFF DISCIPLINE`：巡查結束必留 bundle、明確 blocker、下一個最小命令，不把 repo 舊筆記當 live 真相源。
