## 架構決策紀錄（P2/P3 修訂）

原設計「實體搬進 agent-hq」在執行時發現硬約束：maplab repo 是 **public**，
extension fallback 與 agent 必讀文件都走 maplab 的 raw.githubusercontent 匿名連結；
agent-hq 是 **private**（含 runtime 登記，不宜公開），raw 讀不到。
→ 共用層的「唯一正本」改為「唯一入口」：agent-hq 持 symlink + 位置宣告，
實體留在 public repo。未來若 fallback 改 API+token 或 agent-hq 轉 public，可再物理遷移。
