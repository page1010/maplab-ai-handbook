| `to_b_full`     | 一般企業客戶       | 無訂金 | 企業類 + 未勾選「收訂金」+ 未勾選「行銷/公關」 |

**企業類判定**：
- 公司名欄位有填 **OR**
- 活動類型 ∈ {尾牙, 春酒, 企業, 公司, 記者會, 開幕, 酒會}

**決策樹（Code.gs 實作依據）**：
```
isCorporate = (formData.company.trim().length > 0) OR
              (formData.eventType contains 企業關鍵字)

if (isCorporate) {
  if (isMarketingAgency)  → to_b_marketing
  else if (hasDeposit)    → to_b_deposit
  else                    → to_b_full
} else {
  → to_c   // 個人版一律有訂金
}
```

## 【版本一】`to_c` — 個人版｜有訂金

『簽約使用條款及細則』

### 第一條｜訂單與付款

訂金繳付後，若客戶自行取消服務，訂金不予退還。
客戶須支付尾款於活動日前完成匯款，或於活動當日擺設完畢後以現金或匯款方式支付尾款。
若因不可抗力因素（如天災、重大疫情、本人或直系親屬重大傷病，需附醫療或官方證明），請於活動前7日內主動提出證明，可申請延期或轉讓一次（限6個月內使用）。
活動當日取消或更動者，須支付總金額80%作為食材與人力成本賠償，恕不退還任何已付金額。
活動日前 14 日為最終人數與餐點確認日，其後之增減，本公司將依實際狀況評估是否調整，並保留加收費用或無法調整之權利。
本報價單自提供日起 14 日內有效，逾期將依當時食材成本與檔期重新報價。
本報價內容提供 3 次內調整（包含餐點、份量、擺設形式等），超過次數之修改，將酌收專案調整費或重新報價。
若報價經多次調整後仍未確認，或超過報價有效期限未完成訂單確認，本公司得暫停後續調整與保留檔期之義務。
付款方式以現金或匯款為主，匯款金額須為實收金額，不得扣除手續費後轉帳。
因本公司為小型團隊營運，帳務流程以簡化為主，付款方式以現金或匯款為主，暫不提供支票付款方式，敬請見諒。

### 第二條｜現場服務

若活動指定地點距離門市超過30分鐘車程，需額外收取車馬費，具體費用依公里數報價。
餐點放置地點若位於2樓無電梯，本公司將收取 $800 人員搬運費，3樓以上無電梯則需由客戶自行搬運。
若當日電梯臨時無法使用，則現場加收 $800 為樓層搬運費（現金支付）。
因前置作業較費時、器具易碎又繁多，送達地點臨近50公尺內必需要有停車位、或無違規被開單風險的停車空間（可接受收費或卸貨車位），並可臨停1小時，也避免找不到車位耽誤活動開始時間。
本公司之服務限於餐點擺設，不協助佈置私人道具。
若因場地尚未開放、前場活動未結束或其他非本公司因素，導致無法依約定時間進場，超過約定時間每30分鐘酌收 $500 等待費（未滿30分鐘以30分鐘計）。
本公司將依雙方約定之時間進行撤場與整理，若因客戶方或現場因素導致延誤撤場，超過約定時間每30分鐘酌收 $500 等待費（未滿30分鐘以30分鐘計）。
本公司服務不包含垃圾清運與場地清潔，如需相關服務須另行報價。

**佈置器材責任：**
本公司提供之佈置器材（如桌巾、盤器、裝飾品等）限於活動期間使用，活動結束後須完整歸還。
本公司撤場時將清點設備，如有遺失、損壞或人為因素導致無法使用，客戶須依原價或修繕費用賠償，會於24小時內確認賠償事宜。

### 第三條｜產品責任與保證

本公司產品每年皆有投保『國泰產物產品責任險』。
餐點需於 2-3 小時內食用完畢，以確保食品安全。
本公司提供符合衛生標準之餐點，餐點於完成擺設並交付後，相關保管責任即由客戶承擔。
交付客戶後如因天候或保存不當導致品質變化，恕不負責。
如有外帶打包，不宜於室溫下久置，打包風險歸屬於客戶，恕不負責。

### 第四條｜合約效力

本合約自雙方確認內容無誤，支付訂金款項後即視為同意本條款，並具法律效力，活動結束且物品檢查無誤後自動失效。
本公司會於活動當日於場地內拍攝紀錄照片，作為品牌與行銷使用，若不同意須事先通知。
任何合約爭議，雙方應以誠信協商解決，若無法達成共識，則由本公司所在地法院管轄。
