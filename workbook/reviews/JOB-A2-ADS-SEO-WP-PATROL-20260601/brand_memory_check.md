# Brand Memory Check — A2 Ads / SEO / WordPress Patrol

Date: 2026-06-01
Role: A2 Ads SEO WordPress Patrol (read-only)

## 1) MAPLAB Brand Value

MAPLAB 的核心價值是「用穩定、細緻、有分寸的專業，把活動現場的體面、節奏、畫面感與餐點品質整合成可交付成果」，不走低價吆喝，不靠強推成交。

## 2) MAPLAB Brand Voice

來源：`skills/brand-voice-guide.md`。

重點：
- 說場景與具體名詞，不用空泛形容。
- 不用硬推銷句型，不用「不是...而是...」等說服式對比。
- 語氣要溫暖、穩定、專業、可被信任。
- 價格溝通先調整方案結構，不先折品牌價值。

## 4) Live Website State Source

A2 的 live state 來源層級：
1. Live URL HTTP 狀態與前台頁面。
2. WordPress public REST / wp-admin read-only evidence。
3. Owner Chrome read-only visual bridge（Google Ads / Meta Ads / WP backend）。
4. Repo 歷史文件只做輔助，不可取代 live 證據。

## 5) Shared MAPLAB + Investment OS Culture Rules

- 證據分層：`VERIFIED`（有檔案/畫面/可重播證據） > `REASONABLE INFERENCE`（由證據推論） > `MISSING DATA`（明確缺口）。
- Approval boundary：未經 Owner/A1 批准，不可發布 WordPress，不可改 Google/Meta Ads，不可碰 Rank Math 付費/退訂，不可讀 secrets。
- Handoff discipline：每次巡檢必留 review bundle、safe fix log、下一步具體命令；狀態以 `CURRENT_STATUS.md` / task card 為準。
