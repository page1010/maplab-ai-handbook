# MAPLAB OpenClaw Closed-Loop Playbook

This is the practical sequence for each local task.

## Loop

1. Read GitHub truth.
2. Load only the task-specific workspace memory.
3. Classify the task.
4. Produce the smallest useful artifact.
5. Write a review bundle.
6. Add relation-graph entries.
7. Write the handoff note.
8. Preserve only the reusable lesson.

## What counts as success

A task is successful when:

- the output is usable
- the output has a consumer
- the next action is explicit
- the evidence bundle exists
- the graph shows how it connects

## What does not count as success

- a pretty answer with no next step
- a long conversation without an artifact
- a run that cannot be reviewed later
- an untracked write to a truth source

## Recommended session record

At the end of each stage, keep this shape:

```md
## Stage Record
- Done:
- Output:
- Consumer:
- Next:
- Blockers:
- Evidence:
```
