| 規則 | 數值 | 說明 |
|------|------|------|
| GFT 成本上限 | 訂單金額 × 1% | 20K訂單 → 上限 NT$200 |

| Level 2 目標成本 | NT$200–250 | 含包材 NT$250 以內 |

## SECTION 4 — 實作建議（QUOTE_DRAFT 整合）

目前 QUOTE_DRAFT Row 20–22：
```
Row 20: 熱客招待 Complimentary（標題）
Row 21: 精選小西點禮盒_12入 → N/A
Row 22: 手工馬卡龍禮盒_6入 → N/A
```

建議改法：
1. Row 21 G欄：加下拉 `是/否`（預設「否」）
2. Row 22 G欄：加下拉 `是/否`（預設「否」）
3. 成本欄（H欄）：`=IF(G21="是", 150, 0)` / `=IF(G22="是", 220, 0)`
4. 這兩行的成本計入「額外成本」但不計入報給客戶的金額
