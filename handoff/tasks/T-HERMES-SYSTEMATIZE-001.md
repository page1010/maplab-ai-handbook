## 2. 「hermes 應該比這個好用吧?」——不是同一種東西,不能比好用

- hermes(現況=免費鏈上游的通用 LLM):會讀需求、會歸納、會寫草稿,**但慢、非決定性、每次答案可能不同、要吃上游額度、而且是外部 API**。
- CUA-S1-FORMS:**只會一件事**,但快、免費、可離線、輸出穩定。
- 所以正確結論不是誰比較好用,而是:**這篇講的架構我們早就在用**——「執行層零 LLM」。它是外部對我方既有規則的一次驗證。
- 它真正戳到的是我們的**缺口**,不是優勢:我們沒有「本機小執行模型」。8/30 拔掉本機 ollama 後,本機沒有可用推論引擎(外接碟只留模型檔;`scripts/hermes_mlx_training_preflight.py` 是 MLX QLoRA 的唯讀 GO/NO-GO 守門,明文寫它本身不啟動任何模型=路線備好但未啟用)。
- 影響**直接打到客資分類**:客戶對話不得送任何第三方 API 或免費鏈,而本機現在沒有模型 → 客資分類現階段只能走確定性腳本+人工抽標。這正是「2.8MB 本機模型」對我們的價值所在。
