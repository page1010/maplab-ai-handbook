## SECTION 0 — 說明

LINE OA 自動回覆兩種模式：
1. **關鍵字自動回覆**（Keyword Reply）：客戶輸入包含關鍵字的訊息 → 自動觸發
2. **歡迎訊息**（Greeting）：首次加入好友時觸發

本腳本輸出格式：
- **JSON** (SECTION 2)：供 LINE Messaging API 或開發參考
- **CSV** (SECTION 3)：供 Owner 手動在 LINE OA Manager 後台逐條貼入

> ⚠️ LINE OA Manager 關鍵字回覆限制：每則 **200 字**上限；一個關鍵字只能對應一組回覆。

**設計原則：** LINE bot 已有 #1-#9 九宮格選單處理 70% 初次詢問。
以下 10 條針對**跳過選單、直接打字**的情況（模式 B），以及高頻補問場景。

## SECTION 4 — 匯入操作步驟（Owner 手動）

1. 登入 [LINE Official Account Manager](https://manager.line.biz/)
2. 左側選 **「自動回覆訊息」** → **「關鍵字回覆」**
3. 點「新增關鍵字回覆」：
   - 回覆名稱 = CSV 的「標籤」欄
   - 關鍵字 = 各欄關鍵字逐一加入
   - 回覆內容 = 貼入 CSV「回覆內容」欄（注意 200 字限制）
4. 開啟 → 儲存

**建議優先序（先設定最高頻）：**
R04（外帶）> R06（服務範圍）> R03（素食）> R01（報價）> 其他

**注意：**
- 關鍵字比對為「包含」模式，不需完全匹配
- 同一則訊息符合多個規則時，只觸發優先序最高的
- 全形/半形不同，建議各添加一次
