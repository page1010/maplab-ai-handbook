# MAPLAB 業務報價助手 — 使用者手冊
版本：v1.0 | 建立：2026-03-29

---

## 這是什麼？

這是 MAPLAB Kitchen 的報價助手系統。業務丟需求進來，系統幫你產出報價草稿，你做最終調整。每次你的修改都會被記錄，讓系統越來越準。

---

## 快速開始（5 分鐘上手）

### Step 1：收到客戶需求

客戶透過 LINE / 電話 / 面談告訴你需求。

### Step 2：填入進件表

打開 Google Sheet：MAPLAB_外燴系統_v0.1
→ 切到「SALES_INTAKE」分頁
→ 填一行新資料：

| 你要填的 | 說明 | 範例 |
|---------|------|------|
| 客戶名稱 | 姓名或公司名 | 王小明 |
| 電話 | 聯絡電話 | 0912-345-678 |
| 活動類型 | 下拉選 | 週歲派對 |
| 活動日期 | 幾月幾號 | 2026-04-15 |
| 人數 | 大約多少人 | 30 |
| 預算 | 客戶說的預算 | 大概兩萬 |
| 地點 | 活動地點 | 台南市東區 |
| 原始需求 | 把客戶說的話貼上來 | 「我想辦寶寶週歲，大概30人，有甜點和鹹食，預算兩萬左右」 |

> 💡 不確定的欄位可以空著，但「原始需求」一定要填，越詳細越好。

### Step 3：等報價草稿

A6（報價助手）會讀你填的內容，產出報價草稿到「QUOTE_WORKBENCH」分頁。
通常 5-10 分鐘內會出來。

### Step 4：你做最終調整

打開 QUOTE_WORKBENCH，找到你的 case。
看 A6 產出的品項、數量、價格，按你的經驗調整。

**常見調整：**
- 換品項（客戶不吃某樣東西）
- 改數量（30 人但要備 35 份）
- 加車馬費（地點比較遠）
- 改條款（企業客戶用企業版）

### Step 5：記錄你的修改（5 秒）

切到「REVISION_LOG」分頁，填一行：

| 你要填的 | 怎麼填 | 範例 |
|---------|--------|------|
| case_id | 從 SALES_INTAKE 複製 | CASE-20260415-001 |
| 被修改區塊 | 下拉選 | 品項 |
| 修改類型 | 下拉選 | 修改品項 |
| 原因 | 下拉選 | 客戶要求 |
| 備註（選填） | 簡單寫 | 客戶不吃蝦 |

> 💡 只要選三個下拉就好，5 秒完成。這些紀錄會讓系統越來越懂你的判斷。

### Step 6：發給客戶

確認沒問題後，把報價發給客戶。
在 SALES_INTAKE 把狀態改成「已報價」。
成交後改成「已成交」。

## 常見問題

**Q: A6 產出的報價跟我想的差很多怎麼辦？**
→ 直接改就好。你的每一次修改都會被記錄，下次類似案件 A6 會更準。

**Q: 客戶需求很模糊怎麼辦？**
→ 先填你知道的，A6 會產出「補問清單」告訴你還需要問客戶什麼。

**Q: 我可以不填 REVISION_LOG 嗎？**
→ 技術上可以，但填了系統才會進步。只要選三個下拉，5 秒。

**Q: 急件怎麼處理？**
→ 在 SALES_INTAKE 的備註寫「急件」，A6 會優先處理。

**Q: 品項不在系統裡怎麼辦？**
→ 先手動寫，然後在 REVISION_LOG 記錄「新增品項」，A1 會定期把新品項加入 Items 表。
