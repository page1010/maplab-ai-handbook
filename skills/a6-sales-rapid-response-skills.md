# A6 業務快反應部隊 — 核心技能書

版本：v1.0 | 建立：2026-03-26 | 維護：A1 Claude Code

> 80/20 原則：只寫最影響成交速度的 3 個技能 + 最容易卡住的點

---

## 技能 1：一鍵提案簡報

**場景**：客戶要提案 → 30 分鐘內產出完整提案包

**做法**：
1. 從 A5 的 QUOTE_DRAFT 拉報價資料
2. 從 A4 的素材庫選 3-5 張活動照片（對應活動類型）
3. 組合成提案結構：
   - 第 1 頁：MAPLAB Kitchen 品牌介紹
   - 第 2 頁：活動方案概覽（人數、場地、形式）
   - 第 3 頁：菜單方案（2-3 套）
   - 第 4 頁：過往活動案例照片
   - 第 5 頁：報價總表 + 聯絡方式
4. 輸出：Google Slides 或 PDF

**容易卡住的點**：
- 不要從零做簡報，用 Google Slides 現有模板套
- 照片選擇標準跟 A2 一樣：無人臉、無外部 logo、食物/場景優先
- 報價數字一定從 A5 拉，不要自己算

**依賴**：A5 報價資料 + A4 素材庫

---

## 技能 2：客戶背景速查

**場景**：見客前 5 分鐘，快速了解這個客戶

**做法**：
1. 搜尋 TimeTree 資料：這個客戶過去訂過幾次、什麼活動、什麼規模
2. 搜尋 QUOTE_DRAFT：過去報過什麼價、成交了沒
3. 整理成一頁摘要：
   - 客戶名 + 聯絡方式
   - 歷史訂單（日期、活動、金額）
   - 偏好（曾經指定的菜色、特殊需求）
   - 建議加購（根據活動類型推薦）

**容易卡住的點**：
- 客戶名可能有不同寫法（「林小姐」vs「林怡佳」），搜尋要模糊比對
- TimeTree 資料是 JSON 格式，客戶名在 event title 裡
- 新客戶沒有歷史資料 → 改為分析同類型活動的平均數據

**依賴**：data/timetree_events_2022_2026.json + A5 報價資料

---

## 技能 3：活動需求表單生成

**場景**：新客戶詢問 → 產出結構化需求收集表

**做法**：
1. 根據活動類型（週歲/婚禮/企業/茶會）選擇對應模板
2. 必填欄位：日期、人數、預算範圍、場地、用餐形式（buffet/套餐/餐盒）
3. 選填欄位：飲食限制、指定菜色、場佈需求、攝影需求
4. 輸出：可填寫的 Google Form 或簡潔的文字清單

**容易卡住的點**：
- 不要問太多問題嚇跑客戶，必填控制在 5 項以內
- 預算範圍用區間（1-2萬/2-3萬/3-5萬/5萬以上），不要問精確數字
- 表單不是合約，語氣要輕鬆友善
