## 4. VLOOKUP 公式（統整版）

### G 欄（單位售價）
```
=IF(D9="", "", IFERROR(VLOOKUP(D9, Items!C:D, 2, 0), "N/A"))
```
- 查 Items!C 欄（standard_name）→ 返回 D 欄（default_price）
- 全部 G7:G19 統一用此公式

### H 欄（最終售價，可覆蓋）
- Owner 手動填寫，不填時視為同意 G 欄建議價
- 不要加公式，保持空白讓 Owner 填

### I 欄（小計）
```
=IFERROR(IF(H9="", IFERROR(VLOOKUP(D9,Items!C:D,2,0),0), H9) * IF(F9="",1,F9), 0)
```

### E24（餐點小計）
```
=SUMPRODUCT(
  (D9:D19<>"") *
  IFERROR(IF(H9:H19="", VLOOKUP(D9:D19,Items!C:D,2,0), H9:H19), 0) *
  IF(F9:F19="", 1, F9:F19)
)
```

### H32（訂單成本，維持現有）
```
=SUMPRODUCT((D9:D19<>"")*IFERROR(VLOOKUP(D9:D19,Items!C:E,3,0),0)*IF(F9:F19="",1,F9:F19))
```

### H33（毛利率，維持現有）
```
=IF(E24=0,"",TEXT((E24-H32)/E24,"0.0%"))
```
